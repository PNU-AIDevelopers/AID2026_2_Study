## 🚀 진행 방식

1. 해당 주차 범위를 네 명이 소주제별로 나눕니다.
2. **분담 진행 현황**에서 담당 내용과 상태를 기록합니다.
3. 각자 자신의 항목 페이지에 배운 내용을 정리합니다.
4. 주 1회 스터디에서 정리 내용을 공유하고 질문·토론합니다.
5. 스터디 후 새롭게 이해한 내용을 보완하고 상태를 **정리 완료**로 바꿉니다.
