# [AGI Is All You Need(AIAYN)]
## 👋 팀 소개
저희 팀은 자연어 처리 기술이 실제로 어떻게 동작하고 활용되는지를 함께 공부하기 위해 구성된 스터디 팀입니다. 지정 교재를 중심으로 매주 핵심 내용을 학습하고, 배운 개념을 직접 코드로 구현하며 이해도를 높이고자 합니다. 각자 학습한 내용을 공유하고 모르는 부분은 함께 해결하면서, 기초 개념부터 다양한 NLP 모델의 활용까지 차근차근 학습해 나갈 계획입니다. 최종적으로는 팀원 모두가 자연어 처리의 전반적인 흐름을 이해하고, 배운 내용을 실제 문제에 적용할 수 있는 역량을 갖추는 것을 목표로 합니다.

## 🎯 스터디 목표
목표 1: NLP의 전체적인 학습 흐름 익히기
목표 2: 교재의 예제와 실습을 직접 수행하며 활용 능력 기르기
목표 3: 꾸준하게 학습과 공유를 통해 팀원 모두 학습 과정 완주하기
