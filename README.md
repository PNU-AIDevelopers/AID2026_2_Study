# 같이머신

## 👋 팀 소개

부산대학교 AID 초심자 트랙의 머신러닝 스터디 팀입니다.
함께 머신러닝의 기초를 배우고, 실습과 질의응답을 통해 학습 내용을 이해하고자 합니다.

---

## 🎯 스터디 목표

- 파이썬 기초와 머신러닝 핵심 개념 이해하기
- 교재 예제를 직접 실행하며 모델의 작동 방식 익히기
- 학습 내용을 정리하고 팀원들과 공유하기

---

| 이름 | 역할 |
|---|---|
| 최정인 | 팀장 |

| 박현준 | 팀원 |
| 전해일 | 팀원 |

---

## 📖 학습 자료

- 교재: 혼자 공부하는 머신러닝+딥러닝
- 실습 환경: Google Colab
- 기타 자료: 팀원별 학습 정리 및 실습 코드

---

## 🚀 진행 방식

- 매주 정해진 범위를 각자 학습
- 팀원별 학습 내용 정리 및 공유
- 스터디에서 질의응답 및 토론 진행
- 주차별 활동 기록과 학습 자료를 GitHub에 업로드
- 세부 일정과 발표 방식은 팀원 간 협의 예정
