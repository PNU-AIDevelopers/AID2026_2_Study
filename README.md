# Computer Vision

## 👋 팀 이름: pixelight

OpenCV를 활용하여 컴퓨터 비전의 기본 개념과 영상 처리 기법을 학습하는 엔지니어 트랙 스터디입니다.

---

## 🎯 스터디 목표

- OpenCV의 기본 사용법과 영상 처리 기법 학습
- 컴퓨터 비전의 핵심 개념 이해
- 주차별 실습을 통한 OpenCV 활용 능력 향상

## 🚀 진행 방식

- 매주 정해진 교재 범위를 학습합니다.
- 학습한 내용을 정리하고 예제 코드를 직접 실습합니다.
- 스터디 시간에는 주요 개념 및 실습 내용을 공유하고 질의응답을 진행합니다.
- 주차별 활동 내용과 학습 자료를 GitHub에 기록합니다.
- 1주차와 2주차는 일정 조율을 위해 한 번의 스터디로 통합하여 진행합니다.
- 단, 1주차와 2주차의 GitHub 기록 및 업로드는 각각 별도로 진행합니다.
- 실제 스터디 진행일과 GitHub 업로드일은 서로 다르게 진행합니다.
