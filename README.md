# 말뭉치작업반 (Corpus_Working_Group)

## 👋 팀 소개

저희 팀은 동아리 지정 교재를 기반으로, 현대 NLP 기술의 핵심인 트랜스포머 아키텍처를 깊이 있게 탐구합니다. 혼자 읽으면 놓치기 쉬운 복잡한 이론들을 주차별로 함께 짚어보고, 허깅페이스 라이브러리를 활용해 실전 코드로 직접 구현해 보는 것을 목표로 합니다. 어려운 부분은 자유롭게 토론하고 아는 지식은 적극적으로 공유하며, 팀원 모두가 끝까지 지치지 않고 완주하는 스터디를 만들어 가겠습니다.

---

## 🎯 스터디 목표

- 목표 1 : 트랜스포머 핵심 구조 및 주요 모델 원리 확실히 다지기 (어텐션 메커니즘, BERT·GPT 계열 특징 이해)
- 목표 2 : 허깅페이스 라이브러리를 활용한 주요 NLP 태스크(텍스트 분류, 요약, 질의응답 등) 전처리 및 파인튜닝 직접 구현하
- 목표 3 : 이론과 실습의 균형을 잡으며 8주간 팀원 전원이 성실하게 완주하기
