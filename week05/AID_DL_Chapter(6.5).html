드롭아웃의 효과

  • 드롭아웃을 적용하자 훈련·시험 데이터의 정확도 차이가 감소
  • 훈련 데이터 정확도가 100%에 도달하지 않게 됨
  • ➜ 표현력을 높이면서도 오버피팅을 억제할 수 있다

💡 앙상블 학습(Ensemble learning)과의 관계

여러 모델을 따로 학습시키고, 추론 시 출력을 평균 내는 방식입니다. 드롭아웃은 뉴런을 무작위로 삭제하여 매번 다른 모델을 학습시키는 것으로 볼 수 있고, 추론 시 출력에 삭제 비율을 곱해 평균 효과를 냅니다. 즉 앙상블과 비슷한 효과를 하나의 네트워크로 구현한 셈입니다.

가중치 감소

값을 적절히 설정하지 않으면 모델 성능이 크게 떨어질 수 있습니다. 값 결정에는 많은 시행착오가 필요하므로, 최대한 효율적으로 탐색하는 방법이 중요합니다.

6.5.1

검증 데이터가 필요한 이유

  • 지금까지는 훈련 데이터(학습)와 시험 데이터(범용 성능 평가)로만 분리
  • 하이퍼파라미터 성능을 평가할 때 시험 데이터를 사용하면 안 된다

⚠️ 이유

시험 데이터로 하이퍼파라미터를 조정하면 값이 시험 데이터에 오버피팅됩니다. 시험 데이터에만 맞춰진 값은 다른 데이터에서 범용 성능이 떨어질 수 있습니다.

➜ 하이퍼파라미터 조정 전용 데이터인 검증 데이터(validation data)가 필요합니다.

훈련 · 검증 · 시험 데이터의 역할

🏋️

훈련 데이터

매개변수(가중치·편향) 학습

🔍

검증 데이터

하이퍼파라미터 성능 평가

🧪

시험 데이터

신경망의 범용 성능 확인
마지막에 (이상적으로는 한 번만) 사용

MNIST에서 검증 데이터 분리하기

MNIST는 훈련/시험 데이터만 제공 ➜ 훈련 데이터의 20%를 검증 데이터로 분리

# 훈련 데이터를 뒤섞는다.
(x_train, t_train), (x_test, t_test) = load_mnist()
x_train, t_train = shuffle_dataset(x_train, t_train)

# 20%를 검증 데이터로 분할
validation_rate = 0.20
validation_num = int(x_train.shape[0] * validation_rate)

x_val = x_train[:validation_num]
t_val = t_train[:validation_num]
x_train = x_train[validation_num:]
t_train = t_train[validation_num:]

분리 전에 입력 데이터와 정답 레이블을 함께 뒤섞는 이유: 데이터가 치우쳐 있을 수 있기 때문입니다 (예: 0~9 순서대로 정렬). shuffle_dataset은 np.random.shuffle을 이용하며 common/util.py에 있습니다.

6.5.2

하이퍼파라미터 최적화의 핵심

'최적 값'이 존재하는 범위를 조금씩 좁혀가는 것

🎲 무작위 샘플링

그리드 서치 같은 규칙적 탐색보다 무작위 탐색이 더 좋은 결과를 내는 것으로 알려져 있음 (하이퍼파라미터마다 최종 정확도에 미치는 영향력이 다르기 때문)

📏 로그 스케일

범위를 '대략적으로' 지정. 예: 0.001 ~ 1,000 (10-3~103)처럼 10의 거듭제곱 단위

⏱️ 짧은 에폭

딥러닝 학습은 오래 걸리므로, 나쁜 값은 일찍 포기. 에폭을 작게 해 1회 평가 시간 단축

최적화 절차 요약

0단계

하이퍼파라미터 값의 범위를 설정

1단계

설정된 범위에서 값을 무작위로 추출

2단계

샘플링한 값으로 학습하고 검증 데이터로 정확도 평가 (에폭은 작게)

3단계

1~2단계를 특정 횟수(예: 100회) 반복, 정확도 결과를 보고 범위를 좁힘

범위가 충분히 좁아지면 그 안에서 값을 하나 골라냅니다.

참고: 더 세련된 방법

베이즈 최적화 (Bayesian optimization)

지금까지 설명한 방법은 실용적이지만 과학적이기보다는 수행자의 '지혜'와 '직관'에 의존하는 느낌이 있습니다. 베이즈 최적화는 베이즈 정리를 중심으로 한 수학 이론으로 더 엄밀하고 효율적으로 최적화를 수행합니다.

📄 참고: 〈Practical Bayesian Optimization of Machine Learning Algorithms〉

이번 장에서 배운 내용

  • 매개변수 갱신 방법: SGD 외에도 모멘텀, AdaGrad, Adam 등
  • 가중치 초깃값 설정은 올바른 학습에 매우 중요 — Xavier / He 초깃값이 효과적
