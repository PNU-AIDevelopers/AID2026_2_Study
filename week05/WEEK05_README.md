# Week 05 — 머신러닝: 객체 검출 및 특징 추출·매칭

> **학습 교재:** 『파이썬과 OpenCV4를 활용한 컴퓨터 비전과 머신러닝』 (김찬수·김형오)  
> **학습 범위:** 제Ⅲ장 머신러닝, **1. 객체 검출(204-226쪽) 2. 특징 추출 및 기술자(227-239쪽)**  
> **팀 구성:** 팀장 1명, 팀원 3명

## 🎯 이번 주 목표

- 객체 검출의 기본 원리를 이해하고 템플릿 매칭, 코너점 검출, Haar-like, HOG, LBP 특징의 사용 목적과 차이를 정리한다.
- 영상의 **특징(Feature)**과 **기술자(Descriptor)**의 역할을 구별하고, OpenCV에서 사용하는 특징 추출 방법을 학습한다.
- Brute-Force Matcher와 FLANN Matcher의 특징점 매칭 원리를 이해하고, 교재 예제를 바탕으로 결과 비교 기준을 정리한다.
- 각 기술의 활용 분야와 한계를 확인하여 향후 영상 인식 프로젝트에 적용할 수 있는 기초를 마련한다.

## 📚 스터디 진행상황

### 진행 내용

1. **3장 1절 — 객체 검출(204~226쪽)**
   - **1.1 템플릿 매칭:** 입력 영상에서 작은 기준 영상(템플릿)을 이동시키며 유사도를 계산하는 방법을 학습하였다. 제곱 차이(SQDIFF), 상관관계(CCORR), 상관계수(CCOEFF) 기반 비교 방식의 차이를 정리하였다.
   - **1.2 코너점 검출:** 밝기 변화가 여러 방향으로 크게 발생하는 지점을 코너로 판단하는 원리를 확인하고, Harris 코너 검출과 비최대 억제의 개념을 정리하였다.
   - **1.3 Haar-like 특징:** 밝고 어두운 영역의 차이를 이용한 특징과 얼굴 검출 사례를 살펴보고, 영상 내 객체 크기와 검출 설정이 결과에 영향을 줄 수 있음을 확인하였다.
   - **1.4 HOG 특징:** 영상의 에지 방향과 크기를 히스토그램 형태로 표현하여 사람 형태의 검출에 활용하는 원리를 학습하였다.
   - **1.5 LBP 특징:** 중심 픽셀과 주변 픽셀의 밝기 비교로 이진 패턴을 생성하며 얼굴 및 질감 분석에 활용할 수 있음을 정리하였다.
2. **3장 2절 — 특징 추출 및 기술자(227~239쪽)**
   - **2.1 특징 및 기술자:** 특징점은 영상에서 식별력이 높은 위치이며, 기술자는 해당 위치 주변의 정보를 수치화한 표현이라는 차이를 정리하였다.
   - **2.2 OpenCV의 특징 및 기술자:** Good Features to Track, FAST, SIFT, SURF, BRIEF, ORB 등 교재에서 소개하는 방법의 특징과 사용 목적을 비교하였다.
   - **2.3 특징점 매칭:** Brute-Force 방식과 FLANN 방식의 기본 원리를 비교하고, 특징점 검출 → 기술자 계산 → 거리 기반 매칭 → 매칭 결과 시각화의 처리 흐름을 정리하였다.
3. **학습 결과 정리:** 방법별 핵심 개념, 대표 활용 분야, 결과에 영향을 미치는 조건과 다음 실습 시 확인할 사항을 정리하였다.

## 📎 공부 내용 정리

### 핵심 학습 내용

- **객체 검출:** 템플릿 매칭과 영상 특징을 사용하여 영상에서 관심 객체 또는 관심 영역을 찾아내는 기술.
- **특징점 검출:** 영상에서 반복적으로 구별하기 쉬운 코너 등 주요 위치를 찾는 단계.
- **특징 기술자:** 특징점 주변의 밝기·기울기 등의 정보를 표현하여 다른 영상의 특징과 비교할 수 있도록 하는 값.
- **특징점 매칭:** 서로 다른 영상에서 기술자의 유사도를 계산하고, 대응되는 위치를 연결하는 과정.
- **BF Matcher / FLANN Matcher:** 전자는 후보 기술자와 직접 거리 비교를 수행하고, 후자는 근사 최근접 탐색을 활용해 대규모 특징 탐색의 효율을 높이는 데 초점을 둠.

- **좋았던 점:** 객체 검출에 쓰이는 기법을 개별적으로 암기하는 대신, 어떤 영상 특징을 활용하는지에 따라 비교하면서 학습 내용을 체계적으로 정리할 수 있었다. 특히 특징점 검출과 기술자 생성, 매칭이 이어지는 전체 흐름을 파악할 수 있었다.

- **개선할 점:** 다음 스터디에서는 동일한 입력 영상을 이용해 각 알고리즘의 결과를 비교하고, 사용한 파라미터·처리 시간·매칭 개수를 기록하여 설명과 실습 결과를 연결할 계획이다.
