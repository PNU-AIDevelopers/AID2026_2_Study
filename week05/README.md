## 📝 주요 학습 내용

### 1. 토큰화와 단어 벡터

- 단어 및 문자 단위 토큰화의 장단점을 비교하고 서브워드 방식이 필요한 이유를 학습하였다.
- BPE가 빈번하게 등장하는 문자 조합을 병합하여 어휘를 구성하는 방식을 살펴보았다.
- 한국어의 형태소 경계와 서브워드 분할 결과가 항상 일치하지 않는다는 점을 확인하였다.
- n-gram의 희소성 문제와 word2vec의 분산 표현 방식을 비교하였다.

### 2. LLM 임베딩과 Self-Attention

- word2vec의 단어 표현과 문맥에 따라 달라지는 LLM의 토큰 표현을 비교하였다.
- RNN이 긴 문장의 앞부분 정보를 처리할 때 겪는 한계를 학습하였다.
- Query, Key, Value가 토큰 사이의 관계를 계산하는 데 사용되는 방식을 정리하였다.
- 어텐션 점수를 sqrt(d_k)로 나누는 이유와 문맥에 따른 표현 변화를 살펴보았다.

### 3. 멀티헤드·마스크·위치 정보

- 여러 Attention Head가 서로 다른 관계를 병렬로 학습하는 구조를 살펴보았다.
- Causal Mask가 생성 시 미래 토큰을 참조하지 못하도록 제한하는 이유를 정리하였다.
- 사인파 위치 인코딩과 RoPE의 위치 정보 표현 방식을 비교하였다.
- 한국어에서 어순과 조사 등 위치 정보가 문맥 해석에 주는 영향을 논의하였다.

### 4. Transformer 블록과 토큰 생성

- Attention과 FFN의 역할을 비교하고 Transformer 블록의 구성을 학습하였다.
- 잔차 연결과 층 정규화가 깊은 네트워크의 학습을 돕는 이유를 살펴보았다.
- 출력 로짓을 확률분포로 변환해 다음 토큰을 선택하는 과정을 정리하였다.
- temperature와 top-p가 생성 결과의 다양성에 미치는 영향을 비교하였다.
