# Week 05 — 학습 관련 기술들 (Chapter 6)

## 🎯 이번 주 목표

- SGD, 모멘텀, AdaGrad, Adam의 매개변수 갱신 방법을 이해한다.
- 가중치 초기화(Xavier·He)와 배치 정규화의 목적과 효과를 이해한다.
- 오버피팅을 억제하는 가중치 감소·드롭아웃과 검증 데이터를 활용한 하이퍼파라미터 최적화 방법을 이해한다.

---

## 📚 스터디 진행상황

교재 6장을 중심으로 신경망의 학습 성능을 높이기 위한 매개변수 갱신, 가중치 초기화, 배치 정규화, 오버피팅 억제 및 하이퍼파라미터 최적화 방법을 정리했다.

### 진행 내용

- **6.1 매개변수 갱신:** SGD의 특징과 한계를 살펴보고, Momentum·AdaGrad·Adam의 갱신 방법 및 결과를 비교한다.
- **6.2 가중치의 초깃값:** 가중치를 0으로 초기화할 때의 문제와 활성화값의 분포를 살펴보고, Xavier·He 초기화를 설명한다.
- **6.3 배치 정규화:** 미니배치의 평균·분산을 이용한 정규화 방법과 배치 정규화 계층의 구성 및 학습 효과를 설명한다.
- **6.4 바른 학습을 위해:** 오버피팅을 살펴보고, 가중치 감소와 드롭아웃을 이용해 오버피팅을 억제하는 방법을 설명한다.
- **6.5 적절한 하이퍼파라미터 값 찾기:** 검증 데이터의 역할과 하이퍼파라미터 최적화 과정을 설명한다.
- **6.6 정리:** 6장에서 다룬 학습 관련 기술의 핵심 내용을 정리한다.

## 💬 스터디 회고

- **좋았던 점:** 단순히 가중치를 갱신하는 방법뿐 아니라 초기화와 배치 정규화가 학습의 안정성과 속도에 어떤 영향을 주는지 함께 살펴보며, 학습 관련 기술들의 목적을 연결해 이해할 수 있었다.
- **어려웠던 점:** Xavier·He 초기화가 서로 다른 활성화 함수에 적합한 이유와 배치 정규화에서 평균·분산을 조정한 뒤 다시 확대·이동하는 이유를 이해하는 데 시간이 필요했다.
- **개선할 점:** 각 기법의 수식과 목적을 정리하는 데서 그치지 않고, 교재의 그래프와 코드 실행 결과를 비교해 실제 학습 과정에서 나타나는 차이를 확인한다.
