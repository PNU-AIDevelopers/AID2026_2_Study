7.7.2 · 대표적인 CNN

LeNet의 기본 흐름을 유지하면서 모델의 규모와 학습 방식을 확장했다.

5 + 3

Conv · 합성곱 계층

작은 필터를 이미지 위로 밀며 에지·질감 같은 국소 패턴을 찾는다. 모든 위치에 같은 필터를 쓰므로 매개변수가 적다.

FC · 완전연결 계층

모든 입력을 모든 출력 뉴런과 연결해 특징을 종합하고 판단한다. 교재 5장의 Affine 계층과 같다.

최대 풀링

Conv1 · Conv2 · Conv5 뒤에서 크기를 줄인다. 3×3 창을 2칸씩 옮겨 창끼리 겹친다.

7.7.2 · AlexNet이 더한 세 가지

ReLU · LRN · 드롭아웃

구조는 LeNet과 비슷하지만, 크고 깊은 모델을 학습시키기 위한 장치를 더했다.

ReLU

Rectified Linear Unit · 활성화 함수

무엇?
음수는 0, 양수는 그대로 내보낸다.
f(x) = max(0, x)
어디에?
Conv1~5FC1FC2각 출력 뒤
왜?
계산이 간단하고 기울기가 잘 전달된다. 논문 실험에서 tanh보다 약 6배 빠르게 같은 훈련 오차에 도달했다.

LRN

Local Response Normalization · 국소 응답 정규화

무엇?
같은 위치의 이웃 채널 5개 반응으로 나눠, 특히 크게 반응한 채널을 돋보이게 한다.
b = a ÷ (k + α·Σ a²)β
어디에?
Conv1·2→ReLU→LRN→풀링
왜?
뇌의 '측면 억제'에서 착안. 논문에서 오차 1.2~1.4%p 감소.
지금은?
이후 효과가 작다고 보고되어 배치 정규화(6.3절)로 대체됐다.

드롭아웃

Dropout · 과적합 억제 (6.4.3절)

무엇?
학습할 때 뉴런 출력을 확률 0.5로 무작위로 0으로 만든다.
어디에?
FC1FC2매개변수가 몰린 곳
왜?
특정 뉴런에 기대지 않게 해 과적합을 줄인다. 시험할 때는 모든 뉴런을 쓰고 출력에 0.5를 곱한다.

성과 · ILSVRC-2012 top-5 오차 15.3% (2위 26.2%) — 딥러닝 열풍의 출발점

심화 ① · 깊은 모델의 학습 구조

ResNet 2015 / 2016 · 잔차 연결

순차적인 처리 경로에 입력을 직접 전달해 더하는 경로를 추가한다.

y = F(x) + x

원하는 출력 H(x)를 통째로 배우는 대신, 차이 F(x) = H(x) − x 만 배운다.

F(x) · 학습하는 변화량

입력에 무엇을 더할지 학습한다.

x · 그대로 전달한 입력

지름길을 통해 정보를 전달한다.

입력과 출력의 차원이 같은 덧셈 지점 기준

심화 ① · 잔차를 숫자로 이해하기

변화가 필요 없다면 F(x)를 0으로 만들면 된다

블록은 입력에 더할 값을 학습한다. 필요한 변화만 표현할 수 있다.

설명용 숫자 예시 · 실제 학습 결과 아님

입력 2.0에 변화량 0.5를 더하면, 결과는 2.5가 된다.

심화 ① · ResNet 전체 구조

같은 블록을 단계별로 반복해 쌓는다

ResNet-50 기준 · 단계가 바뀔 때마다 가로·세로는 절반, 채널 수는 2배가 된다.

지름길의 두 종류

항등 지름길크기·채널이 같을 때 · x를 그대로 더함 · 매개변수 추가 없음
투영 지름길모양이 다를 때 · 1×1 합성곱(스트라이드 2)으로 x의 크기·채널을 맞춘 뒤 더함

블록의 두 종류

기본 블록3×3 → 3×3 · ResNet-18 / 34
bottleneck1×1 → 3×3 → 1×1 · ResNet-50 / 101 / 152 · 채널을 줄였다 늘려 계산량 절약

전역 평균 풀링 = 채널마다 7×7 전체의 평균 하나만 남김 · 152층 ResNet 앙상블, ILSVRC 2015 우승(top-5 오차 3.57%)

심화 ① · 역전파로 보는 잔차 연결

덧셈 노드는 기울기를 그대로 흘려보낸다

5장 계산 그래프에서 본 덧셈 노드의 역전파 규칙이 지름길에도 그대로 적용된다.

∂L/∂x = ∂L/∂y × (∂F/∂x + 1)

+1 · 지름길로 온 기울기

덧셈 노드는 상류 기울기를 그대로 전달한다. F를 거친 기울기가 작아져도 ∂L/∂y는 앞쪽 층에 도착한다.

∂F/∂x · 블록을 거친 기울기

블록 안의 가중치는 이 경로의 기울기로 학습된다.

스칼라로 단순화한 식 · 원 논문은 '항등 함수에 가까운 해를 찾기 쉬워진다'는 최적화 관점으로 설명하며, 역전파 관점은 이해를 돕는 보조 설명
