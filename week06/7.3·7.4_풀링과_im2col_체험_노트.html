7.4.3 · 7.4.4 코드

⑦ 책의 구현 코드, 줄마다 읽기

위에서 만져 본 것이 코드의 어느 줄에 해당하는지 대응시켜 보세요. 예시는 MNIST(입력 (10,1,28,28), 필터 (30,1,5,5), stride 1, pad 0)입니다.

Convolution.forward 
def forward(self, x):
    FN, C, FH, FW = self.W.shape          # (30, 1, 5, 5)
    N, C, H, W = x.shape                  # (10, 1, 28, 28)
    out_h = int(1 + (H + 2*self.pad - FH) / self.stride)   # 24   ← ⑤의 OH 식
    out_w = int(1 + (W + 2*self.pad - FW) / self.stride)   # 24
    col   = im2col(x, FH, FW, self.stride, self.pad)       # (5760, 25)  ← ④
    col_W = self.W.reshape(FN, -1).T                       # (25, 30)    필터를 열로
    out   = np.dot(col, col_W) + self.b                    # (5760, 30)  ← ③ w·x + b 를 한 번에
    out   = out.reshape(N, out_h, out_w, -1).transpose(0, 3, 1, 2)   # (10, 30, 24, 24)
    return out
Pooling.forward 
def forward(self, x):
    N, C, H, W = x.shape                  # 앞 층 출력 (10, 30, 24, 24)
    out_h = int(1 + (H - self.pool_h) / self.stride)       # 12
    out_w = int(1 + (W - self.pool_w) / self.stride)       # 12
    col = im2col(x, self.pool_h, self.pool_w, self.stride, self.pad)   # (1440, 120)
    col = col.reshape(-1, self.pool_h*self.pool_w)         # (43200, 4)  ← ⑥ 채널 분리
    arg_max = np.argmax(col, axis=1)                       # 역전파용으로 최댓값 위치 저장
    out = np.max(col, axis=1)                              # (43200,)    ← ① 최댓값
    out = out.reshape(N, out_h, out_w, C).transpose(0, 3, 1, 2)   # (10, 30, 12, 12)
    return out

합성곱: Affine 계층과 같은 식입니다. dW = colᵀ·dout, dcol = dout·col_Wᵀ. 그 뒤 col2im이 겹친 칸을 더해서 입력 모양으로 되돌립니다(한 입력 칸이 여러 윈도우에서 쓰였으니 기울기도 합쳐야 하기 때문).

풀링: 순전파에서 저장한 arg_max 위치에만 dout을 보내고 나머지는 0입니다. ReLU의 역전파와 같은 발상입니다.

⑧ 의문 정리

공부하다 나온 질문과 답입니다. 관련 데모가 있는 것은 해당 위치로 연결했습니다.

Q1. 필터를 퍼셉트론의 가중치로 보면, 연결선이 뻗어가는 것과 같은가?

네, 같은 구조입니다. 출력 한 칸은 f(w·x + b)입니다. 윈도우 9칸이 입력, 필터 9개 값이 가중치, 편향이 b인 퍼셉트론 하나입니다(③, ④). 완전연결 계층과 다른 점은 두 가지뿐입니다.

완전연결(Affine)합성곱
한 출력이 연결된 입력전체 입력윈도우 안의 칸만(국소 연결)
출력 칸마다 가중치모두 다른 값모든 위치에서 같은 필터 공유

입력 (1,28,28)에서 출력 (30,24,24)를 만들 때 매개변수는 완전연결이 13,564,800개(편향 포함), 합성곱(필터 30개 5×5)이 780개입니다. ⑤ 계산기에서 MNIST 예시로 확인할 수 있습니다. 합성곱은 "완전연결에서 대부분의 연결을 지우고, 남은 연결의 가중치를 위치끼리 묶은 것"입니다. 학습할 때 필터의 기울기는 모든 위치에서 온 기울기를 합한 값입니다.

Q2. 그림 7-12에서 편향을 더해도 출력이 그대로인 것 같은데, 편향의 의미는?

편향을 더하면 값은 바뀌지만 모든 칸이 같은 만큼 바뀌어서 칸끼리의 차이(모양)는 그대로입니다. 편향의 역할은 활성화 함수(ReLU)와 만났을 때 드러납니다. 편향은 "얼마나 강해야 반응했다고 칠지"의 기준선(퍼셉트론의 임계값 θ = −b)입니다.

③의 슬라이더로 b를 −10, −16까지 내리면 ReLU 뒤에서 약하게 반응한 칸부터 꺼집니다. 필터 하나에 편향 하나이고 모든 출력 칸에 같은 값을 더합니다(shape (FN,1,1)).

Q3. 윈도우 3, stride 2는 어떻게 되나? (윈도우 3, stride 3이 아닐 때)

4×4 입력이면 OH = 1 + (4−3)/2 = 1.5로 나누어떨어지지 않고, 책 구현은 int()로 1을 씁니다. 윈도우는 한 번만 놓이고 마지막 행·열은 쓰이지 않습니다. 5×5 입력이면 OH = 2로 딱 맞고 가운데 열이 겹칩니다. ①-2의 예시 버튼으로 바로 볼 수 있습니다.

이런 "윈도우가 stride보다 큰" 겹치는 풀링은 실제로 쓰입니다. AlexNet이 3×3 윈도우를 stride 2로 적용합니다(55→27, (55−3)/2+1 = 27). 책이 "윈도우 = stride가 보통"이라고 한 것은 가장 단순한 경우를 말한 것입니다. 출처는 맨 아래 링크를 보세요.

Q4. "학습할 매개변수가 없다"는 사용자 설정으로 구동되는 명령어 같은 것인가?

네, 그 느낌이 맞습니다. 다만 설정값과 학습 매개변수를 구분하면 정확해집니다.

계층사람이 미리 정하는 설정값학습으로 정해지는 값
합성곱필터 개수·크기, stride, pad필터 안의 숫자, 편향
풀링윈도우 크기, stride없음
Affine출력 뉴런 수가중치 W, 편향 b

풀링은 "최댓값을 고른다"는 규칙이 고정되어 있고 인자(크기, stride)만 넘기는 함수 호출에 가깝습니다. 풀링에도 역전파는 일어납니다(최댓값이었던 위치로만 기울기가 전달). 갱신할 값이 없을 뿐입니다. ⑤ 계산기의 "풀링 매개변수 0개" 행에서도 확인할 수 있습니다.

Q5. 윈도우가 3×2처럼 정사각형이 아니면 stride는 어떻게 정하나?

가로·세로에 각각 따로 정합니다. "윈도우 = stride" 규칙은 축마다 성립합니다.

윈도우 (3, 2)  →  stride (3, 2)      # 세로 3칸씩, 가로 2칸씩
OH = 1 + (H − pool_h) / stride_h
OW = 1 + (W − pool_w) / stride_w

6×6 입력이면 OH = 2, OW = 3이라 출력은 (2,3)이고 겹침도 건너뜀도 없습니다. stride를 숫자 하나(3)로 통일하면 가로에서 열 2, 5를 건너뛰고, 2로 통일하면 세로가 겹칩니다. ①-2에서 둘째·셋째 예시를 비교해 보세요.

책 구현은 윈도우는 pool_h, pool_w로 따로 받지만 stride는 숫자 하나를 가로·세로에 똑같이 씁니다. 그래서 3×2에 (3,2) stride는 지금 코드로 표현할 수 없고 im2col의 stride도 확장해야 합니다. PyTorch는 정수 하나 또는 (높이, 너비) 튜플을 받고, stride를 생략하면 kernel_size와 같아집니다.

pool = nn.MaxPool2d(kernel_size=(3, 2))   # stride 생략 → (3, 2)

실무에서는 정사각형 윈도우가 거의 대부분입니다.

참고 (책 밖 보충): PyTorch에서는 im2col과 같은 일을 하는 torch.nn.Unfold가 있고, NVIDIA GPU 라이브러리는 im2col 행렬을 통째로 만들지 않는 Implicit GEMM 방식을 씁니다.
