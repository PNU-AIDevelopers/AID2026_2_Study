7.4.1 / 4차원 배열

CNN의 입력은 4차원 배열

여러 장의 이미지를 한 번에 처리하려면 이미지 번호와 채널, 높이, 너비를 구분해야 합니다.

(10, 1, 28, 28)
N이미지 수
C채널 수
H높이
W너비

인덱스 하나가 축 하나를 고릅니다

  • x.shape → (10, 1, 28, 28)
  • x[0].shape → (1, 28, 28)
  • x[0, 0].shape → (28, 28)

이 예에서 입력은 28×28 흑백 이미지 10장입니다.

필터 창 하나를 한 행으로

입력 위의 필터 창을 왼쪽 위부터 이동시키며, 각 창에 든 값을 순서대로 펼칩니다.

입력 이미지 (4 × 4)

선택한 창을 펼친 행

전체 im2col 행렬

교재 243–245쪽 · 시연은 채널 1개의 작은 예시입니다.

7.4.2–7.4.3 / 행렬의 형태

im2col 행렬의 크기 구하기

행의 개수는 배치 전체에서 필터를 놓는 횟수이고, 열의 개수는 창 하나에 들어가는 원소 수입니다.

일반식

(N × OH × OW, C × FH × FW)

OH, OW는 출력 높이와 너비, FH, FW는 필터 높이와 너비입니다.

한 축의 출력 크기는 ⌊(입력 + 2×패딩 − 필터) / 스트라이드⌋ + 1입니다.

교재 예제

입력은 채널 3개, 7×7입니다. 5×5 필터를 한 칸씩 옮기면 가로 3곳, 세로 3곳에 놓을 수 있습니다.

(9, 75)
이미지 1장
(90, 75)
이미지 10장

창이 겹치면 같은 입력값이 여러 행에 들어갑니다. 메모리 사용량은 늘 수 있고, 연산은 최적화된 행렬 곱으로 처리할 수 있습니다.

교재 244–245쪽

7.4.3 / 합성곱 계층

합성곱을 행렬 곱으로 계산

펼친 입력 창과 펼친 필터의 내적을 한꺼번에 구하고, 필터별 편향을 더합니다.

순전파 구현

patches = im2col(x, FH, FW, stride, pad)
filters = W.reshape(FN, -1).T
scores = patches @ filters + b
out = scores.reshape(N, OH, OW, FN)
out = out.transpose(0, 3, 1, 2)

예시의 배열 크기

  1. 입력 창 (9, 75) × 필터 (75, 10)
  2. 행렬 곱 결과 (9, 10)
  3. 공간 축 복원 (1, 3, 3, 10)
  4. 채널 축 이동 (1, 10, 3, 3)

여기서는 필터 수 FN = 10입니다.

역전파에서는 col2im으로 창의 기울기를 입력 좌표에 돌려놓습니다. 여러 창이 공유한 좌표에는 기울기를 더합니다.

교재 244–247쪽

7.4.4 / 최대 풀링

최대 풀링은 창마다 최댓값 선택

출력 칸을 누르면 어느 입력 창에서 최댓값을 가져왔는지 볼 수 있습니다.

입력 (4 × 4)

출력 (2 × 2)

2×2 풀링 · 스트라이드 2

rows = im2col(x, 2, 2, stride=2)
rows = rows.reshape(-1, 4)
values = rows.max(axis=1)
out = values.reshape(N, OH, OW, C)
out = out.transpose(0, 3, 1, 2)

채널별로 창을 독립적으로 처리합니다. 역전파에서는 순전파에서 최댓값을 선택한 위치에 기울기를 전달합니다.
