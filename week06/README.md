## 📚 스터디 진행상황

CNN의 합성곱 연산 방식, 패딩과 스트라이드를 이용한 연산 방식 이해. 합성곱 연산을 3차원 블럭 데이터 형태로 이해. 폴링계층 및 최대폴링, 평균폴링에 대한 이해. im2col을 이용한 합성곱/폴링계층 구현. 이를 통한 CNN구현 및 시각화. 그 외 대표적인 CNN및 그 외 학습 신경망 알고리즘에 대한 이해.

---

### 진행 내용

- 합성곱 연산: 2차원 입력 데이터 형태를 2차원 필터를 통해서 곱셈 연산 및 편향을 더하는 방식.
- 패딩, 스트라이드: 합성곱 연산시 입력 데이터 주변을 특정 값으로 채워 출력 크기를 조정할 수 있는 패딩과 필터의 위치 간격을 조정하는 스트라이드를 이용해 합성곱 연산을 조정할 수 있음.
- 3차원 합성곱 연산: 기존 2차원 데이터의 높이, 너비에 채널을 더한 3원 데이터를 이용하여 합성곱 연산 가능
- 폴링계층: 필터 없이 윈도우 만으로 윈도우 안의 최대 값을 구하는 연산을 최대폴링, 윈도우 안의 값의 평균을 구하는 연산을 평균 폴링이라 하며 CNN에서는 주로 최대폴링을 사용하며, 스트라이드는 윈도우의 크기의 한쪽 길이로 함.
- 합성곱/폴링계층 구현: im2col을 사용하여 3차원 입력 데이터를 2차원 행렬로 바꾸는 방식으로 행렬의 곱을 사용하여 합성곱 연산을 구현함. 똑같은 방식으로 폴링계층도 구현.
- CNN구현: 기존의 Affine 방식이 아닌 Conv>ReLU>Pooling을 사용하여 신경망 층을 구현함
- 그 외 학습 알고리즘 신경망: 기존 CNN을 LeNet이라 하며, 여기서 ReLU함수 사용 국소적 정규화 및 드롭아웃을 사용하여 AlexNet을 구현 가능. 그 외 학습 알고리즘으로 순차적인 처리 경로에 입력을 그대로 추가하는 ResNet, Transformer강세이던 시기에 있던 ConvNeXt가 있음
