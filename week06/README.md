## 📝 주요 학습 내용

### 1. 무엇을 학습 목표로 삼나

- 다음 토큰의 확률을 계산하고 정답 토큰의 확률을 높이는 학습 방식을 살펴보았다.
- 교차 엔트로피에서 정답 토큰의 예측 확률이 높을수록 손실이 작아지는 이유를 정리하였다.
- Perplexity의 의미를 살펴보고 동일한 평가 데이터와 토큰화 기준에서 비교해야 함을 확인하였다.
- 다음 토큰 예측을 통해 문법과 문맥 등을 학습하는 과정, 언어의 불확실성 때문에 손실이 일반적으로 0이 될 수 없는 이유를 학습하였다.

### 2. 어떤 데이터를 먹이나

- 같은 문서의 반복이 학습에 미치는 영향을 살펴보고 중복 제거가 필요한 이유를 정리하였다.
- 품질 필터링으로 유용한 학습 텍스트를 선택할 때 고려할 기준을 살펴보았다.
- 웹, 책, 코드 등 데이터의 특성을 비교하고 목적에 맞는 혼합 비율이 필요한 이유를 학습하였다.

### 3. 키우면 얼마나 좋아지나

- 모델 크기, 학습 데이터 양, 계산량을 늘릴 때 손실이 감소하는 양상을 멱법칙과 연결해 살펴보았다.
- 계산 예산이 정해졌을 때 모델 크기와 데이터 양의 균형을 맞추는 Chinchilla의 관점을 학습하였다.
- 작은 모델에 많은 데이터를 학습시키는 이유를 추론 비용과 연결해 정리하였다.

### 4. 여러 언어를 한 모델에 담으려면

- 같은 내용이라도 언어에 따라 토큰 수가 달라져 비용과 문맥 길이에 차이가 생기는 이유를 살펴보았다.
- 언어별 샘플링 비율 p ∝ n^α를 조정할 때 저자원 언어의 학습 기회와 데이터 반복이 어떻게 바뀌는지 비교하였다.
- 언어 간 전이와 모델 용량의 희석을 함께 살펴보며 언어 수가 늘 때 성능이 달라지는 이유를 정리하였다.
- 한국어와 저자원 언어를 중심으로 학습 데이터와 토큰 효율의 차이를 논의하였다.
