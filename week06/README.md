# Week 06 — 합성곱 신경망(CNN) (Chapter 7)

## 🎯 이번 주 목표

- 기존 완전연결 신경망과 CNN의 구조적 차이를 이해한다.
- 합성곱·풀링 계층의 연산 원리와 구현 방법을 이해한다.
- CNN의 학습된 필터를 시각화하고, LeNet·AlexNet의 특징을 이해한다.

---

## 📚 스터디 진행상황

교재 7장을 중심으로 CNN의 전체 구조, 합성곱·풀링 계층, 구현 방법, 학습된 특징의 시각화 및 대표적인 CNN 모델을 정리한다.

### 진행 내용

- **7.1 전체 구조:** 기존 완전연결 신경망과 CNN을 비교하고, 합성곱·풀링 계층이 추가된 CNN의 구조를 설명한다.
- **7.2 합성곱 계층:** 합성곱 연산, 패딩, 스트라이드, 3차원 데이터의 합성곱 연산 및 필터의 구조를 설명한다.
- **7.3 풀링 계층:** 풀링 연산과 주요 특징을 설명한다.
- **7.4 합성곱/풀링 계층 구현하기:** 4차원 배열과 im2col을 이용한 합성곱·풀링 계층 구현 방법을 살펴본다.
- **7.5 CNN 구현하기:** 합성곱·풀링 계층을 조합한 CNN의 구성과 학습 방법을 살펴본다.
- **7.6 CNN 시각화하기:** 학습 전후 필터의 가중치를 비교하고, 층이 깊어질수록 추출하는 특징이 달라지는 과정을 설명한다.
- **7.7 대표적인 CNN:** LeNet과 AlexNet의 구조 및 특징을 비교한다.
- **7.8 정리:** 7장에서 다룬 CNN의 핵심 내용을 정리한다.
