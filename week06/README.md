#### 주요 학습 내용

**내용 1 - 추천시스템 평가 방법**

| 평가 방법 | 핵심 목적 | 대표 방법 |
| --- | --- | --- |
| 오프라인 평가 (Offline Evaluation) | 저장된 데이터로 모델 성능 검증 | RMSE, nDCG, MAP |
| 온라인 평가 (Online Evaluation) | 실제 사용자 행동 및 서비스 성과 확인 | A/B 테스트, 인터리빙 |
| 사용자 스터디 (User Study) | 사용자의 만족도와 경험 직접 조사 | 인터뷰, 설문, ResQue |

- 오프라인 평가의 높은 점수가 실제 서비스 성과를 보장하지 않음
- 추천 품질, 실제 사용자 행동, 주관적 만족도를 상호 보완적으로 평가할 필요성

**내용 2 - 오프라인 평가 지표**

| 평가 대상 | 대표 지표 | 핵심 질문 |
| --- | --- | --- |
| 예측 오차 | MAE, MSE, RMSE | 실제 평점을 얼마나 정확히 예측했는가? |
| 추천 집합 | Precision@K, Recall@K, F1 | 추천 목록에 적합한 아이템이 얼마나 포함됐는가? |
| 추천 순위 | MRR, MAP, nDCG | 적합한 아이템을 얼마나 상위에 배치했는가? |
| 추천 특성 | Coverage, Novelty, Diversity, Serendipity | 다양한 아이템과 새로운 발견을 제공하는가? |

**핵심 수식**

- `Precision@K = 상위 K개 중 적합한 아이템 수 / K`
- `Recall@K = 상위 K개 중 적합한 아이템 수 / 전체 적합 아이템 수`
- `F1 = 2 × Precision × Recall / (Precision + Recall)`
- `nDCG@K = DCG@K / IDCG@K`

**내용 3 - 모델 검증 및 온라인 평가**

- **Train / Validation / Test:** 학습·설정 조정·최종 성능 평가를 위한 데이터 구분
- **데이터 누수 (Data Leakage):** 미래 데이터가 학습에 포함되지 않도록 주의
- **모델 튜닝 (Model Tuning):** 수동 튜닝, 그리드 서치, 베이즈 최적화
- **A/B 테스트 (A/B Test):** 사용자 집단을 나누어 변경 사항의 효과 비교
- **OEC:** 실험 성공 여부를 판단하는 핵심 지표
- **가드레일 지표 (Guardrail Metrics):** 응답 속도 및 오류율 등 악화 여부 점검
- **인터리빙 (Interleaving):** 서로 다른 추천 순위를 섞어 상대적 선호 평가

**내용 4 - 사용자 스터디 및 경험 평가**

- **참가자 선정:** 조사 목적과 실제 서비스 사용자 특성을 고려
- **샘플링:** 단순 무작위·계통·층화·임의 추출
- **피험자 내 측정:** 동일 참가자가 여러 시스템을 비교
- **피험자 간 측정:** 서로 다른 참가자 집단을 비교
- **캐리 오버 효과 (Carry-over Effect):** 학습·피로 등에 따른 순서 영향
- **카운터 밸런스 (Counterbalancing):** 평가 순서를 조정하여 순서 효과 감소
- **ResQue:** 시스템 품질, 사용자 신념, 사용자 태도, 행동 의도 평가

#### 중요하게 본 내용

- 추천 정확도와 실제 사용자 만족도는 서로 다른 평가 대상
- Precision과 Recall은 상호 보완적인 관계이며, 서비스 목적에 맞는 선택 필요
- 추천 결과의 다양성·신규성·흥미로움도 사용자 경험에 영향을 미침
- 클릭률 증가만으로 구매 전환이나 사용자 만족도 개선을 단정하기 어려움
- 그룹 추천에서는 전체적인 품질뿐 아니라 개별 구성원의 만족도를 함께 고려할 필요성

#### 스터디 후 보완

- 모델 정확도와 실제 서비스 성과의 차이 이해
- Precision@K와 nDCG의 평가 대상 차이 정리
- MRR과 MAP의 사용 상황 구분
- 콜드 스타트 상황에서 기본 추천과 행동 데이터 수집의 필요성 확인
- 그룹 영화 추천 서비스에 적용할 평가 지표 추가 검토

### Week 06 · 추천시스템 평가

**기록 기준일:** 2026.11.16

**토론 참여 기록:** 이윤성, 이동민, 김민서, 안현지, 노시은

**모임 날짜:** 별도 확인 필요

**학습 범위:** Chapter 7

### 토론 1 - 그룹 추천의 평가 기준

**질문:** 그룹 영화 추천 시스템에서는 전체 추천 정확도와 개별 구성원의 만족도 중 무엇을 더 중요하게 평가해야 할까?

- **이윤성:** 추천 정확도만으로 만족도가 보장되지 않으므로 nDCG와 사용자 스터디를 함께 활용할 필요성
- **이동민:** 개별 구성원의 만족도를 우선 고려하고 이후 전체적인 평가 요소를 반영하는 방식 제안
- **김민서:** 모든 팀원의 취향을 아우르는 전체 추천 정확도를 상대적으로 중요하게 평가
- **안현지:** 한 명이라도 강하게 비선호하는 영화가 있으면 그룹 만족도가 떨어질 수 있으므로 개별 만족도를 중시
- **노시은:** 함께 즐기는 그룹 추천의 목적을 고려하여 구성원별 만족도를 중요하게 평가

**토론 정리**

- 전체 정확도와 개별 만족도 사이의 평가 우선순위에 다양한 의견 존재
- 그룹 전체 추천 품질과 구성원별 만족도를 함께 고려하는 평가 방법 검토 필요

### 토론 2 - Precision과 Recall

**질문:** 영화 추천 서비스에서는 Precision과 Recall 중 무엇을 더 중요하게 평가해야 할까?

- **공통 의견:** 제한된 추천 목록에서 사용자가 좋아할 영화를 충분히 제공하는 것이 중요하므로 Precision@K를 우선 고려
- **추가 검토:** 추천 목록의 길이와 적합한 영화의 배치 순서까지 고려할 필요성

**토론 정리**

- 상위 추천 결과의 적합도를 중요하게 평가
- Precision@K 외에 nDCG와 같은 순위 기반 지표의 병행 검토

### 토론 3 - 콜드 스타트 문제

**질문:** 사용자 데이터가 부족할 때 추천 모델을 개선하는 것과 기본 추천을 제공하는 것 중 어느 쪽이 적절할까?

- **공통 의견:** 초기에는 인기 아이템 기반의 기본 추천을 제공하고, 이후 사용자 행동 데이터를 수집하여 추천 품질을 개선하는 방향
- **추가 검토:** 초기 선호도 입력과 기본 추천을 결합하는 방법

**토론 정리**

- 데이터가 부족한 신규 사용자를 위한 기본 추천 필요
- 사용자 피드백 축적 후 개인화 추천으로 확장하는 방식 검토

### 토론 4 - 오프라인 지표와 온라인 지표의 차이

**질문:** nDCG가 높은 모델이 실제 서비스에서 낮은 클릭률을 보인다면 어떤 지표를 우선해야 할까?

- 온라인 행동 지표를 중심으로 실제 서비스 성과 확인 필요
- 클릭률과 함께 체류 시간, 이탈률 등 후속 행동 분석 필요
- 추천 상위 항목의 특성과 노출 위치 검토 필요
- 오프라인 지표와 실제 사용자 행동 사이의 차이를 분석하여 평가 기준 개선

**토론 정리**

- 오프라인 성능만으로 모델 적용 여부를 결정하지 않음
- 실제 서비스 목표와 평가 결과의 관계를 검토
- 원인 분석 이후 최종 평가 지표 선정 필요

### 토론 5 - 정확도와 다양성

**질문:** 추천 정확도가 높은 시스템과 다양성·신규성이 높은 시스템 중 어느 쪽을 선택해야 할까?

- **공통 의견:** 서비스 목적과 사용자의 행동 의도에 따라 평가 기준을 다르게 설정
- 정확도가 높은 추천을 기본으로 하되 다양하고 새로운 아이템의 노출도 고려
- 단기적인 추천 품질뿐 아니라 장기적인 사용자 만족도 검토 필요

**토론 정리**

- 정확도와 다양성은 서로 다른 측면을 평가
- 하나의 지표만으로 최종 추천 품질 판단 불가
- 사용자 만족도와 재방문 의향 등 추가 기준 필요

## 🎬 프로젝트와 스터디 연계

### 「우리끼리 뭐 볼까?」 평가 방안

**프로젝트 목표**

여러 사용자의 영화 선호도를 종합하여 그룹 전체가 함께 만족할 수 있는 영화 추천

### 1. 추천 알고리즘 평가

- Precision@K: 추천된 영화 중 실제 선호 영화의 비율 확인
- Recall@K: 전체 선호 영화 중 추천 목록에 포함된 비율 확인
- nDCG@K: 선호도가 높은 영화를 상위에 배치했는지 평가
- RMSE: 평점 예측 모델을 사용할 경우 예측 오차 확인

### 2. 그룹 만족도 평가

- 그룹 구성원별 추천 영화 평점 또는 선호도 비교
- 구성원 중 가장 낮은 선호도를 보이는 경우 확인
- 그룹 전체 평균 만족도와 개별 구성원의 만족도 함께 검토
- 특정 사용자의 취향이 과도하게 반영되는 문제 분석

### 3. 추천 다양성 평가

- 추천 목록에 포함된 영화 장르의 다양성
- 인기 영화에 대한 추천 편중 여부
- 사용자가 접하지 못했던 새로운 영화 추천 여부
- 예상하지 못했지만 만족스러운 영화 발견 여부

### 4. 사용자 스터디

- 친구·커플·가족 등 그룹 유형별 사용자 경험 조사
- 추천 결과의 만족도와 유용성 평가
- 추천 이유에 대한 이해도와 신뢰도 확인
- 추천 목록에서 최종 영화를 결정하기까지의 편의성 평가
- 서비스 재사용 의향 조사

### 5. 향후 적용 검토

- 추천 알고리즘별 오프라인 평가 결과 비교
- 그룹 구성원 간 선호도 차이를 반영하는 평가 기준 설계
- 소규모 사용자 스터디를 통한 실제 만족도 측정
- 충분한 사용자와 로그가 확보될 경우 온라인 평가 도입 검토
