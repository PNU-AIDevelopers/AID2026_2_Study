## 📎 공부 내용 정리

- 확률적 경사 하강법은 일부 데이터로 모델을 여러 번 갱신한다. 에포크는 전체 훈련 데이터를 한 번 사용하는 단위다.
- 결정 트리는 분할 후의 불순도가 낮아지는 방향으로 질문을 선택한다.
- 교차 검증은 설정을 평가하는 방법이고, 그리드 서치는 여러 설정을 비교해 적절한 조합을 찾는 방법이다.
- 랜덤 포레스트는 여러 트리의 예측을 합치고, 부스팅은 앞선 모델의 오차를 줄이는 방향으로 트리를 순서대로 추가한다.
