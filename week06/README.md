## 📚 공부 내용 정리

### 1. 앙상블 학습과 정형 데이터

앙상블 학습은 여러 모델의 예측을 결합하여 최종 예측을 만드는 방식임. 와인의 알코올 도수·당도·pH처럼 행은 샘플, 열은 특성으로 구성되는 정형 데이터에 트리 기반 모델을 적용할 수 있음.

| 구분 | 학습 방식 | 대표 모델 |
|---|---|---|
| 배깅 | 재표집한 데이터로 모델을 독립적으로 학습하고 예측을 결합 | 랜덤 포레스트 |
| 무작위 트리 앙상블 | 특성과 분할 임곗값에 무작위성을 부여한 트리들을 결합 | 엑스트라 트리 |
| 부스팅 | 현재 모델의 손실을 줄이는 방향으로 모델을 순차적으로 추가 | 그레이디언트 부스팅, 히스토그램 기반 부스팅 |

분류는 투표 또는 클래스 확률 결합, 회귀는 예측값 평균 등의 방법을 사용함. 사이킷런의 랜덤 포레스트 분류기는 트리별 클래스 확률을 평균한 뒤 가장 높은 확률의 클래스를 선택함.

### 2. 랜덤 포레스트와 OOB 점수

- **부트스트랩:** 원본 훈련 세트에서 복원 추출하여 트리별 학습 데이터를 만듦. 같은 샘플이 여러 번 선택되거나 한 번도 선택되지 않을 수 있음.
- **무작위 특성 선택:** 각 노드에서 일부 특성을 후보로 골라 최선의 분할을 찾음. 서로 다른 트리의 예측이 지나치게 비슷해지는 것을 줄이는 데 도움이 됨.
- **예측 결합:** 여러 트리의 결과를 평균하여 단일 트리의 변동성을 줄임. 과대적합이 완전히 없어지는 것은 아님.
- **OOB:** 특정 트리의 부트스트랩 학습에 포함되지 않은 샘플을 의미함. 크기 N인 데이터에서 N번 복원 추출하면 각 샘플이 제외될 확률은 `(1 - 1/N)^N`이며, N이 크면 약 36.8%임.

**원문 설명 보완:** `oob_score_`는 트리별 정확도의 단순 평균이 아님. 각 샘플을 학습에 사용하지 않은 트리들의 예측을 모아 샘플별 OOB 예측을 만들고, 이를 정답과 비교하여 점수를 계산함. OOB는 내부 평가에 활용할 수 있지만 최종 테스트 세트의 역할과는 구분함.

분류기의 기본 `max_features='sqrt'`에서 특성 3개이면 분할 후보 특성 수는 1개임. 원문의 특성 2개 선택 예시는 설정을 변경한 경우로 이해해야 함. [RandomForestClassifier 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html)

### 3. 엑스트라 트리

엑스트라 트리는 기본적으로 `bootstrap=False`이므로 각 트리가 전체 훈련 데이터를 사용함. 후보 특성별 무작위 임곗값으로 분할 후보를 만든 뒤 그중 좋은 분할을 선택함. 아무 기준 없이 최종 분할을 정하는 것은 아님.

분할 임곗값 탐색을 단순화하여 계산량을 줄일 수 있으며, 무작위성을 통해 트리의 다양성을 높임. 랜덤 포레스트와의 속도·정확도 차이는 데이터와 설정에 따라 달라지므로 검증 점수로 비교함. [ExtraTreesClassifier 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.ExtraTreesClassifier.html)

### 4. 그레이디언트 부스팅과 히스토그램 기반 부스팅

그레이디언트 부스팅은 현재 예측의 손실을 줄이는 방향으로 새 트리를 순서대로 추가함. 제곱 오차 회귀에서는 잔차를 학습하는 것으로 이해할 수 있고, 일반적으로는 손실의 음의 그래디언트를 이용함.

- `learning_rate`: 새 트리가 예측에 기여하는 정도를 조절함.
- `n_estimators`: 부스팅 단계를 조절함. 학습률·트리 깊이와 함께 검증해야 함.
- `subsample`: 단계마다 사용할 훈련 샘플 비율을 조절함.
- 트리를 추가할수록 훈련 점수가 좋아져도 검증 점수가 계속 좋아진다고 보장할 수 없음.

히스토그램 기반 부스팅은 연속 특성을 구간으로 묶어 분할 탐색을 효율화함. `max_bins=255`가 기본이며 비결측값 구간 외에 결측값용 구간을 추가함. 반복 횟수는 `max_iter`로 조절하고 결측값을 직접 처리할 수 있음. 모든 데이터에서 다른 모델보다 빠르거나 정확한 것은 아님. [HistGradientBoostingClassifier 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)

### 5. 와인 분류 원문 결과 비교

다음은 6주차 자료가 제시한 교차 검증 점수임. 검증 점수와 별도의 최종 테스트 점수를 구분함.

| 모델 | 훈련 정확도 | 검증 정확도 |
|---|---|---|
| 랜덤 포레스트 | 0.997 | 0.891 |
| 엑스트라 트리 | 0.997 | 0.889 |
| 그레이디언트 부스팅 기본 모델 | 0.888 | 0.872 |
| 그레이디언트 부스팅: 트리 500개, 학습률 0.2 | 0.946 | 0.878 |
| 히스토그램 기반 그레이디언트 부스팅 | 0.932 | 0.880 |

- 랜덤 포레스트의 OOB 점수는 0.893으로 제시됨.
- 히스토그램 기반 부스팅의 최종 테스트 정확도는 0.872로 제시됨.
- 랜덤 포레스트와 엑스트라 트리는 높은 훈련 점수에 비해 검증 점수가 낮아 과대적합 여부를 살펴볼 필요가 있음.
- 부스팅 설정 변경 시 훈련 점수는 0.888에서 0.946으로, 검증 점수는 0.872에서 0.878로 상승함. 훈련·검증 격차도 커지므로 트리 증가가 항상 과대적합을 억제한다고 해석하지 않음.

### 6. 특성 중요도와 순열 중요도

원문의 랜덤 포레스트 특성 중요도는 알코올·당도·pH 순으로 `[0.232, 0.500, 0.268]`, 엑스트라 트리는 `[0.202, 0.522, 0.276]`임. 이전 깊이 제한 단일 트리의 `[0.123, 0.869, 0.008]`과 비교하면 당도에 집중되었던 중요도가 다른 특성에도 분산됨.

순열 중요도는 특성 하나의 값을 섞기 전후의 점수 차이로 모델의 해당 특성 의존도를 살펴보는 방법임. 중요도가 인과관계를 뜻하지 않으며, 불순도 기반 중요도와 순열 중요도는 계산 방식이 달라 수치를 직접 같은 척도로 비교하지 않음.

### 7. 응용: 터치펜 인식 오류와 좌표 보정 실험계획

참고 자료의 주제는 **외부 자기장에 의한 스마트패드 터치펜 인식 오류 분석 및 머신러닝 기반 좌표 보정**임. 아래 내용은 실험 설계와 분석 계획이며, 보정 성능이 검증되었다는 의미는 아님.

#### 문제 정의와 데이터 구성

- 좌표 왜곡: 펜촉의 기준 위치와 인식된 좌표가 달라져 직선이 휘어 기록되는 현상
- Dead Zone: 필기가 인식되지 않아 궤적이 끊기는 구간
- 데이터 단위: 궤적을 이루는 각 절점의 좌표 `(x, y)`를 하나의 샘플로 구성
- 기록 항목: 홀 센서 전압 변화량, 간섭원과의 거리·상대 위치, 인식 좌표, 기준 좌표와의 오차, 필기 끊김 여부
- 영점 보정: 태블릿만 놓았을 때의 전압을 기준으로 외부 간섭원 배치 후 전압 변화량을 계산
- 학습·평가 계획: 세기가 다른 자석 1·2·3으로 학습하고, 분리해 둔 무선이어폰 충전 케이스 조건에서 일반화 성능 확인

외부 정자기장에 초점을 맞추되 필압·펜 기울기 등의 영향을 실제로 배제하려면 측정 조건을 일정하게 유지해야 함.

#### 모델별 역할

| 단계 | 모델·방법 | 입력과 예측 대상 |
|---|---|---|
| 필기 끊김 판별 | 로지스틱 회귀 | 물리적 기준 거리·자기장 세기로 끊김 여부의 확률 예측 |
| 좌표 오차 보정 기준 모델 | 다변수 2차 다항 회귀 | 상대 좌표·거리·자기장 세기로 가로·세로 오차 예측 |
| 비선형 좌표 오차 보정 | RBF 커널 SVR | 표준화된 특성으로 가로·세로 오차를 각각 예측 |
| 미인식 구간 연결 | 선형 또는 3차 스플라인 보간 | 보정한 경계 절점을 이용하여 누락된 구간 추정 |

보정 좌표는 `인식 좌표 - 예측 오차`로 계산함. SVR용 스케일러는 훈련 데이터만으로 학습하고 검증·테스트 데이터에는 같은 변환을 적용함. 좌표가 없는 절점은 좌표 회귀 학습에서 제외하되, 끊김 분류에는 관측 가능한 입력과 끊김 라벨을 사용할 수 있음.

다항 회귀 보정은 계획된 유효 반경 안에서 적용하고, 보간한 구간은 실제로 관측한 좌표와 구분함. 보간은 누락된 궤적을 추정하는 방법이며 실제 경로의 복원을 보장하지 않음.

#### 평가 계획과 보완점

- 끊김 분류: 정확도와 F1 점수로 평가
- 좌표 보정: 보정 전후 위치 RMSE, R², 기준 직선으로부터의 수직 거리 비교
- 시각화: 기준 직선·보정 전 궤적·다항 회귀 보정·SVR 및 보간 결과를 겹쳐 표시
- 데이터 분할 보완: 같은 궤적의 인접 절점이 훈련·검증에 섞이지 않도록 측정 회차나 궤적 단위로 분리
- 평가 조건 보완: 충전 케이스 데이터를 최종 평가용으로 사용할 경우, 해당 결과를 보고 설정을 반복 조정하지 않음

### 8. 질문 및 정리

**Q1. 여러 트리를 사용하면 과대적합이 없어질까?**

트리의 다양성과 예측 결합이 변동성을 줄일 수 있지만 과대적합을 완전히 막지는 못함. 훈련·검증 점수 차이와 하이퍼파라미터를 함께 확인해야 함.

**Q2. 분류와 회귀를 나누는 이유는 무엇일까?**

필기 끊김 여부는 범주를 예측하는 분류 문제이고, 인식된 좌표의 가로·세로 오차는 연속값을 예측하는 회귀 문제이기 때문임.

**Q3. 좌표가 끊긴 구간에 회귀 보정만 적용할 수 있을까?**

인식 좌표 자체가 없으면 그 좌표에서 오차를 빼는 보정을 바로 수행할 수 없음. 관측된 경계점을 보정한 뒤 보간으로 누락 구간을 추정하는 별도 단계가 필요함.

터치펜 사례를 통해 샘플·특성·타깃을 실제 측정 데이터에 대응시키고, 하나의 실험 안에서도 분류·회귀·보간이 서로 다른 역할을 맡는다는 점을 정리함. 다음 실험에서는 데이터 누수 방지와 보정 전후의 정량 평가를 우선 확인할 필요가 있음. 개인별 소감은 별도 기록되지 않음.
