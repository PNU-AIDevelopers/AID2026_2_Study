## 📚 스터디 진행상황

날씨 도구를 호출해 옷차림을 추천하는 에이전트를 공통 과제로 정하고, 팀원별로 프레임워크를 나눠 구현했다. 5주차 회고에서 정한 대로 프레임워크마다 Colab 노트북을 따로 만들고 패키지 버전을 맞췄다. 스터디 시간에는 각자 노트북을 실행하며 결과를 비교했다.

### 진행 내용

- 공통 과제와 도구 함수 정의, 패키지 버전 고정
- LangChain `create_agent`와 LangGraph 상태 그래프로 같은 에이전트 구현
- AutoGen 단일 에이전트와 검토 에이전트를 붙인 팀 구성, CrewAI 역할 분담 크루 구현
- LlamaIndex `FunctionAgent`와 문서 검색 도구 추가, AutoGPT Platform 블록 구성
- 프레임워크별 구현 결과 비교표 작성

- 개선할 점: 7주차에는 LangSmith로 프레임워크별 호출 수와 실행 시간을 기록해서 비교표를 수치로 보완한다.
