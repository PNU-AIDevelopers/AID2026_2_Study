- 책 자료: 혼자 공부하는 머신러닝+딥러닝
### 1. 학습 주제
- K-최근접 이웃(KNN) 알고리즘
- 훈련 데이터와 정답 데이터
- fit(), predict(), score()의 역할

### 2. 학습 내용
KNN은 새로운 데이터와 기존 데이터 사이의
거리를 계산하고, 가까운 이웃의 정보를 활용해
분류하거나 예측하는 알고리즘이다.

### 3. 실습 및 느낀 점
직접 실습하면서 predict()가 데이터의 순서와
상관없이 거리를 기반으로 이웃을 찾는다는 점을
이해했다.
