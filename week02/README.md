## 📖 학습 내용

### 기본 개념

- 특성과 모델, 지도 학습과 비지도 학습
- 훈련 세트와 테스트 세트의 역할 및 분할
- k-최근접 이웃(KNN) 분류와 정확도
- 데이터 전처리, 표준점수, NumPy 브로드캐스팅
- 테스트 데이터에도 훈련 데이터의 평균과 표준편차를 적용하는 이유

### 실습 내용

- 부리 폭(`beak_height`)과 길이(`beak_length`)를 특성으로 사용
- A섬 핀치는 부리의 폭이 작고 길며, B섬 핀치는 폭이 크고 짧음
- 49마리 데이터를 훈련 세트 35마리와 테스트 세트 14마리로 분할
- 산점도로 훈련·테스트 데이터를 구분하고 점의 겹침을 확인

### 질문 및 정리

- `train_input`과 `trian_input`은 서로 다른 변수이며, 노트북에는 이전 실행 결과가 남을 수 있음
- 같은 데이터를 두 번 그리면 나중에 그린 점이 앞의 점을 가릴 수 있음
- 좌표가 가까운 점은 겹쳐 보일 수 있어 크기와 투명도를 조절해 확인
- 노트북은 셀의 위치가 아니라 실제 실행 순서에 따라 변수 상태가 달라짐
- 공유 전 커널을 재시작하고 위에서부터 모두 실행하여 재현 여부 확인
