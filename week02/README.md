## 📚 스터디 진행상황

신경망에대한 기본 구조 및 활성화 함수 개념 및 종류를 알아봄. 다차원 배열과 행렬의 곱을 알아보고, 이를 이용하여 3층 신경망을 구현함.
항등 함수와 소프트맥스 함수를 사용한 출력층을 설계함. MINIST데이터 셋을 이용한 손글씨 분류. 손실함수에 대한 이해 및 손실함수의 종류에 대해 알아봄

---

### 진행 내용

- 신경망: 신경망의 구조는 입력층 은닉층 출력층으로 되어있으며, 퍼셉트론과 크게 다르지 않음
- 활성화 함수: 활성화 함수는 입력 신호의 총합이 활성화를 일으키는지 판단하는 함수로, 시그모이드 함수, 계단 함수, ReLU함수가 있음
- 다차원 배열과 곱: 다차원 배열은 가로 행 세로 열로 구성된 2차원 배열이고, 이러한 배열들을 곱할때는 곱해지는 행렬의 행 곱하는 행렬의 열을 각각 원소를 곱하고 더한 값이됨
- 3층 신경망 구현: 각각의 층에 해당하는 가중치 및 편향을 입력하고 행렬의 곱을 사용해 각 층마다 각각의 입력 값에 따른 활성화를 행렬의 곱과 활성화 함수로 구현함.
- 출력층 설계: 항등 함수를 사용하여 입력된 값을 그대로 출력, 소프트맥스 함수를 사용하여 입력된 값을 확률의 형태로 출력
- 손실 함수: 학습된 결과와 실제 결과가 얼마나 다른지 나타내는 지표로 이를 사용해 매개변수의 최적의 값을 찾을 수 있음
