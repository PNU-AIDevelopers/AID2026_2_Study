## 💬 스터디 회고

- **좋았던 점**
  - 팀원별로 서로 다른 추천 알고리즘을 학습하고 공유하여 다양한 추천 방식의 특징을 종합적으로 이해할 수 있었음
  - RMSE가 낮은 모델이 반드시 Precision@K와 Recall@K에서도 좋은 성능을 보이지는 않는다는 점을 확인하며 평가 목적의 중요성을 이해함
  - 추천 결과의 신뢰성, 시리즈물 중복 추천, 딥러닝 도입 시점 등 실제 서비스 개발과 연결되는 주제로 토론을 진행함
- **어려웠던 점**
  - 행렬 분해와 딥러닝 등 일부 알고리즘의 수학적 원리와 학습 과정이 복잡하여 직관적으로 이해하기 어려웠음
  - 평가 지표별 성능 차이가 발생하는 원인과 데이터 전처리 및 임곗값이 추천 결과에 미치는 영향을 파악하는 데 어려움이 있었음
  - 추천 정확도뿐 아니라 다양성, 신뢰성, 계산 비용 등을 동시에 고려하는 알고리즘 선택 기준이 명확하지 않았음
- **개선할 점**
  - 학습한 알고리즘을 동일한 데이터셋에 적용하여 성능을 직접 비교하는 실습 강화
  - 복잡한 수식과 알고리즘을 간단한 예제 및 코드와 연결하여 이해도 향상
  - 실제 개발할 그룹 영화 추천 서비스의 요구사항을 기준으로 알고리즘별 활용 가능성을 구체적으로 검토
