## 📌 다음 주 계획

### NLP 스터디 가이드라인 1장 — 아키텍처

멘토님께서 제공해 주신 가이드라인을 바탕으로 Transformer와 LLM의 기본 아키텍처를 학습한다. 7개의 주제와 20개의 핵심 질문을 네 파트로 나누어 공부하고 발표할 예정이다.

| 담당 | 발표 주제 | 학습 범위 |
| --- | --- | --- |
| 박근영 | 토큰화와 단어 벡터의 기초 | 1-1 전체, 1-2 Q1~Q2 |
| 마야 | LLM 임베딩과 셀프 어텐션 | 1-2 Q3, 1-3 전체 |
| 박세홍 | 멀티헤드·마스크·위치 정보 | 1-4 전체, 1-5 전체 |
| 신민영 | Transformer 블록과 토큰 생성 | 1-6 전체, 1-7 전체 |

기존에 학습한 내용은 간단히 복습하고, 새롭게 등장하는 개념은 작동 원리와 언어적 특성을 중심으로 심화 학습할 예정이다.
