## 📚 스터디 진행상황

역전파의 연쇄법칙에 대한 이해. 덧셈노드의 역전파, 곱셈노드의 역전파. 덧셈, 곱셈계층의 순전파 역전파 코드 구현. ReLU계층, Sigmoid계층, Affine계층, Softmax With Loss계층 순전파 역적파 이해 및 코드 구현. 오차역전파법을 사용한 딥러닝 알고리즘 구현. 확률적 경사 하감법(SGD), 모멘텀, AdaGrad, Adam등 매개변수 갱신 알고리즘 이해.

---

### 진행 내용

- 연쇄법칙: 합성함수의 미분은 각 구성 함수들의 미분값을 곱한 것과 같다는 미적분학의 규칙.
- 덧셈, 곱셈노드 역전파: 덧셈은 상류에서 전해진 미분값에 1을 곱하여 하류로 흐르고, 곱셈은 입력 신호들을 서로 바꾼 값을 곱해서 하류로 흐른다.
- ReLU계층, Sigmoid계층 역전파: ReLU는 입력값이 0보다 크면 상류에서 전해진 미분값에 1을 곱하고, 0이하면 0을 곱하여 하류로 보낸다. Sigmoid는 상류의 미분값에 y(1-y)(y = 출력값)을 곱한 값을 하류로 보낸다.
- Affine계층, Softmax계층 역전파: Affine계층에선 입력값 X, 가중치 W, 편향 B, 출력값 Y(각각 X,W,B,Y는 벡터 혹은 메트릭스)가 있다면, Y에 대한 손실함수의 미분값을 ∂L/∂Y라 하자. 손실함수에 대한B의 미분값은 ∂L/∂Y, X는 ∂L/∂Y * W^T, W는 X^T * ∂L/∂Y로 표현할 수 있다(X^T는 행렬 X에 대한 전치행렬). Softmax-with-Loss계층은 각각의 입력값에 대한 손실함수의 변화량은 각각의 입력값에 따른 softmax출력값의 정답 레이블을 뺀 값이 된다.
- 학습 알고리즘 구현: 전체적인 틀은 앞과정과 똑같이 미니배치, 기울기 산출, 매개변수 갱신 순서로 가며 기존과 다른점은 오차역전파법을 이용해 기울기를 산출한다.
- 매개변수 최적화 알고리즘: 확률적 경사 하강법(SGD)는 앞 장에서 소개한 경사 하강법이며, 이것은 비등방성 함수에서 비효율적이라는 단점이 있다. 이러한 경사하강법에서 속도를 넣어 관성 개념을 추가한 모멘텀이 있다. 그리고 경사 하강법의 학습률을 정할때 학습률을 점차 줄여나가는 AdaGrad방법이 있다. 그리고 모멘텀과 AdaGrad를 적당히 융합한것이 Adam이다.
