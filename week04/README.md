# Week 04 — 컴퓨터 비전 2.5~2.6 스터디

> **교재:** 『파이썬과 OpenCV4를 활용한 컴퓨터 비전과 머신러닝』 (김찬수·김형오)  
> **학습 범위:** Ⅱ. 컴퓨터 비전 — **5. 기하학 변환 (169~189쪽)**, **6. 에지 검출 (190~200쪽)**  
> **팀 구성:** 팀장 1명, 팀원 3명 (총 4명)

## 🎯 이번 주 목표

- OpenCV를 활용한 **기하학 변환**(이동·크기·회전·투시 변환, 모폴로지 연산)의 원리를 이해하고 예제를 실습합니다.
- **에지 검출**(미분 연산 기반 에지 검출, 캐니 에지, 허프 변환을 이용한 직선 및 원 검출)을 학습하고 결과를 비교합니다.
- 담당 범위별 코드, 실행 화면, 핵심 개념을 정리하여 스터디 자료로 공유합니다.

## ✅ 진행상황

- **완료한 내용:** 기하학 변환의 이동·크기·회전·투시 변환과 모폴로지 연산의 주요 개념을 정리하고, 에지 검출의 미분 연산·캐니 에지·허프 변환 원리를 학습하는 범위별 정리를 완료하였습니다.
- **진행 중인 내용:** 각 기법의 OpenCV 예제 실행 결과를 비교하고, 변환 및 검출 결과를 팀원별로 취합하여 정리하고 있습니다.
- **미완료 내용:** 실습 결과를 종합한 최종 발표 자료와 통합 검토는 아직 완료하지 못했습니다.
