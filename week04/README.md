
# Week 04 — 오차역전파법 (Chapter 5)

## 🎯 이번 주 목표

- 계산 그래프의 순전파와 역전파 및 연쇄법칙을 이해한다.
- 덧셈·곱셈 계층과 ReLU·Sigmoid·Affine·Softmax-with-Loss 계층의 순전파·역전파 계산을 이해한다.
- 오차역전파법을 적용한 `TwoLayerNet`의 기울기 계산과 수치 미분을 통한 기울기 확인 과정을 이해한다.

---

## 📚 스터디 진행상황

교재 5장에서는 계산 그래프와 연쇄법칙을 바탕으로 오차역전파법을 설명하고, 여러 계층을 구현하여 신경망의 기울기를 계산한다. 아래는 교재에 수록된 학습 내용이며, 실제 스터디 진행 여부를 의미하지 않는다.

### 진행 내용

- **5.1 계산 그래프:** 계산 과정을 노드와 화살표로 나타내며, 순전파와 역전파를 구분한다.
- **5.2 연쇄법칙:** 합성함수의 미분이 각 함수의 미분을 곱하는 방식으로 계산됨을 설명한다.
- **5.3 역전파:** 덧셈 노드는 기울기를 그대로 전달하고, 곱셈 노드는 반대쪽 입력값을 곱해 전달한다.
- **5.4 단순한 계층 구현:** `MulLayer`, `AddLayer`의 `forward()`와 `backward()`를 구현한다.
- **5.5 활성화 함수 계층:** ReLU와 Sigmoid 계층의 순전파 및 역전파를 설명한다.
- **5.6 Affine/Softmax 계층:** 행렬 곱에 대한 역전파, 배치용 Affine 계층, Softmax-with-Loss 계층을 설명한다.
- **5.7 오차역전파법 구현:** 계층을 조합한 `TwoLayerNet`을 구성하고, 수치 미분과 역전파의 기울기를 비교한 뒤 신경망 학습에 활용한다.
- **5.8 정리:** 계산 그래프와 각 계층의 역전파를 활용해 기울기를 구하는 과정을 정리한다.

## 💬 스터디 회고

- **좋았던 점:** 손실 함수부터 경사하강법과 학습 반복문까지, 개별적으로 보였던 개념이 하나의 학습 과정으로 연결된다는 점을 이해했다. 간단한 수치 계산과 행렬 차원 예제가 개념 이해에 도움이 됐다.
- **어려웠던 점:** 특정 이차함수의 편미분 결과를 모든 손실 함수에 적용할 수 있다고 혼동했다. 또한 기울기의 반대 방향이면 무조건 손실이 감소한다고 생각했던 점, 손실 함수와 정확도 및 훈련 성능과 일반화 성능을 구분하는 점이 어려웠다.
- **개선할 점:** 수식의 의미만 이해하는 데서 그치지 않고 직접 `numerical_gradient`와 `TwoLayerNet` 코드를 실행해 가중치 형태 및 손실·정확도 변화를 확인한다. 개념 설명 뒤에는 작은 계산 문제와 코드 실행 결과를 함께 점검한다.
