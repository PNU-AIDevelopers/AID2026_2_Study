## 배운 내용 정리

## 1. 행렬 분해 개요

> 사용자와 아이템의 평점행렬을 저차원의 사용자 잠재 요인 행렬과 아이템 잠재 요인 행렬로 분해하여, 아직 평가하지 않은 아이템의 선호도를 예측하는 추천 방법
> 

### 행렬 분해의 기본 개념

- 협업 필터링의 대표적인 모델 기반 추천 방법
- 사용자와 아이템의 관계를 수치 벡터로 표현 → 선호도를 예측
- 사용자와 아이템을 동일한 잠재 요인 공간에 배치하고 유사성 계산
- SVD, NMF, MF, IMF, BPR, FM

### 평점 행렬 (Rating Matrix)

- 행(Row) → 사용자
- 열(Column) → 아이템
- 값(Value) → 사용자가 아이템에 부여한 평점
- 관측되지 않은 값 → 아직 평가하지 않은 아이템

### 희소 행렬 (Sparse Matrix)

- 대부분의 사용자가 모든 아이템을 평가하지 않기 때문에 발생함
- MovieLens 예제 → 사용자 1,000명, 아이템 6,673개
- 평점 행렬의 밀도 약 0.02(2%) → 대부분의 값이 비어 있음
- 행렬 분해를 활용하여 관측되지 않은 평점을 예측할 수 있음

### 잠재 요인 (Latent Factor)

> 사용자의 취향과 아이템의 특징을 설명하는 숨겨진 요소
> 
- 사용자 잠재 요인 → 사용자의 어떤 특성을 선호하는지 나타냄
- 아이템 잠재 요인 → 아이템이 어떤 특성을 가지는지 나타냄
- 잠재 요인은 사람이 직접 지정하는 것이 아니라 학습 과정에서 자동으로 발견됨
- 액션 선호도, 판다지 선호도와 비슷한 요인이 형성될 수 있으나, 실제 각 차원의 의미가 명확하게 해석되는 것은 아님

$$

\hat r_{ui}=p_u^\top q_i

$$

- $p_u$ → 사용자 $u$의 잠재 요인 벡터
- $q_i$ → 아이템 $i$의 잠재 요인 벡터
- $\hat r_{ui}$ → 사용자 $u$가 아이템 $i$에 줄 것으로 예측한 평점

## 2. 특이값 분해 (SVD / Singular Value Decomposition)

> 평점 행렬을 세 개의 행렬로 분해하고 중요한 잠재 요인만 남겨 평점을 예측하는 방법
> 

### SVD의 기본 원리

$$

R=PSQ^\top

$$

| 기호 | 의미 |
| --- | --- |
| R | 사용자 × 아이템 평점 행렬 |
| P | 사용자 요인 행렬 |
| S | 특잇값을 담은 대각 행렬 |
| Q_T | 아이템 요인 행렬의 전치 |
- 큰 특잇값에 해당하는 주요 요인만 선택하여 차원을 축소함
- 평점 행렬을 근사적으로 복원하여 결측 평점을 예측함
- 잠재 요인 수 k가 중요한 하이퍼파라미터임

### 결측값 처리

SVD 구현에는 결측값을 어떻게 채우는지가 추천 성능에 영향을 미침

| 결측값 처리 | 특징 |
| --- | --- |
| 0으로 대체 | 미평가 아이템을 0점으로 취급하여 왜곡 가능 |
| 평균 평점으로 대체 | 0 대체보다 성능이 개선될 수 있으나 실제 선호와 다를 수 있음 |

교재 실험 결과

| 결측값 처리 | RMSE | Precision@K | Recall@K |
| --- | --- | --- | --- |
| 0으로 대체 | 3.335 | 0.009 | 0.029 |
| 평균으로 대체 | 1.046 | 0.013 | 0.043 |
- 평균으로 대체했을 때 모든 지표가 개선됨
- 결측값을 0으로 취급하면 평점 예측이 지나치게 낮아질 수 있음
- 실제로 평가하지 않았다는 사실과 싫어한다는 의미는 다름

## 3. 비음수 행렬 분해 (NMF / **Non-negative Matrix Factorization**)

> 행렬을 음수가 아닌 값으로 구성된 두 개의 행렬로 분해하는 방법
> 

### NMF의 기본 원리

$$
R\approx PQ^\top

$$

제약 조건:

$$
P\geq0,\quad Q\geq0
$$

- SVD와 유사하게 잠재 요인을 통해 평점을 예측함
- 사용자와 아이템의 요인 값을 모두 0 이상으로 제한함
- 비음수 데이터를 다룰 때 활용하기 적합함
- 잠재 요인의 가산적 표현을 얻을 수 있다는 특징이 있음

### SVD와 NMF의 차이

| 구분 | SVD | NMF |
| --- | --- | --- |
| 행렬 구성 | 특잇값 분해 | 비음수 행렬 분해 |
| 음수 허용 | 허용 | 허용하지 않음 |
| 잠재 요인 | 양수·음수 가능 | 0 이상 |
| 공통점 | 저차원 요인으로 행렬 근사 | 저차원 요인으로 행렬 근사 |

교재 실험 결과

| 결측값 처리 | RMSE | Precision@K | Recall@K |
| --- | --- | --- | --- |
| 0으로 대체 | 3.348 | 0.010 | 0.032 |
| 평균으로 대체 | 1.045 | 0.012 | 0.040 |
- SVD와 마찬가지로 평균 대체 시 성능 개선
- 결측값 처리 방법이 추천 정확도에 큰 영향을 미침
- SVD와 NMF의 성능 차이는 해당 실험에서 크지 않음

## 4. 명시적인 평가값에 대한 행렬 분해(MF / Matrix Factorization)

> 사용자가 직접 입력한 평점 데이터를 활용하여 사용자와 아이템의 잠재 요인을 학습하는 방법
> 

### MF의 특징

- SVD, NMF와 달리 일반적인 MF 학습에서는 관측된 평점에 대한 오차를 직접 최소화함
- 결측값을 0으로 채워 전체 행렬을 분해할 필요가 없음
- 사용자 아이템의 잠재 요인 벡터를 학습하여 평점을 예측함
- SGD, ALS

### MF의 목적 함수

$$

\min_{P,Q}\sum_{(u,i)\in R^+}
(r_{ui}-p_u^\top q_i)^2
+\lambda(\|p_u\|^2+\|q_i\|^2)

$$

- $R^+$→ 실제 평점이 관측된 사용자·아이템 쌍
- 첫 번째 항 → 실제 평점과 예측 평점의 오차
- 두 번째 항 → 정규화 항으로 과적합 방지
- $\lambda$→ 정규화 강도

### 최적화 방법

**ALS(Altering Least Squares)**

- 사용자 요인과 아이템 요인을 번갈아 고정하면서 최적화함
- 각 단계르 최소제곱 문제로 해결

**SGD(Stochastic Gradient Descent)**

- 개별 측 평점 또는 작은 배치를 활용하여 오차를 계산함
- 손실 함수의 기울기 방향으로 파라미터 갱신

### 편향(Bias)을 포함한 MF

$$

\hat r_{ui}=\mu+b_u+b_i+p_u^\top q_i
$$

- $\mu\$ → 전체 평균 평점
- $b_u$→ 사용자 편향
- $b_i$ → 아이템 편향
- $p_u^\top q_i$ → 잠재 요인을 통한 선호도 예측

모든 영화에 후한 점수를 주는 사용자는 사용자 편향이 높을 수 있음

### 교재 실험 결과

| 실험 조건 | RMSE | Precision@K | Recall@K |
| --- | --- | --- | --- |
| 기본 MF | **0.934** | **0.005** | **0.016** |
| 평가 수 300개 이상 영화로 제한 | **1.148** | **0.016** | **0.054** |
- 기본 MF는 평점 예측 오차(RMSE)가 상대적으로 낮음
- 반면 추천 순위 지표는 낮게 나타남
- 평가 수가 많은 영화로 제한하면 Precision@K와 Recall@K가 개선되지만 RMSE는 악화됨

평점 예측을 잘하는 모델이 반드시 Top-K 추천을 잘하는 모델은 아님

## 5. 암묵적인 평가값에 대한 행렬 분해(IMF / Implicit Matrix Factorization)

> 클릭, 조회, 구매처럼 사용자의 행동으로부터 선호도를 추정하는 암묵적 피드백 기반 행렬 분해 방법
> 

### 명시적 평가와 암묵적 평가

| 구분 | 명시적 피드백 | 암묵적 피드백 |
| --- | --- | --- |
| 데이터 | 별점, 좋아요·싫어요 | 클릭, 조회, 구매, 재생 |
| 선호도 표현 | 사용자가 직접 표현 | 행동으로 간접 추정 |
| 특징 | 선호 의미가 비교적 명확함 | 행동의 의미가 불확실할 수 있음 |
| 예시 | 영화에 5점 평가 | 영화를 여러 번 시청 |

### IMF의 핵심 개념

암묵적 피드백에는 두 가지 정보를 활용함

선호도 $p_{ui}$

$$
p_{ui}=
\begin{cases}
1 & (r_{ui}>0)\\
0 & (r_{ui}=0)
\end{cases}
$$

- 1 → 아이템과 상호작용한 기록이 있음
- 0 → 상호작용 기록이 없음
- 0은 명확한 비선호를 의미하지 않음

신뢰도 $c_{ui}$

$$
c_{ui}=1+\alpha r_{ui}
$$

- $r_{ui}$ → 클릭이나 시청 등의 행동 횟수
- $\alpha$→ 신뢰도 증가 정도를 조절하는 파라미터
- 상호작용이 많을수록 선호도 추정에 대한 신뢰도를 높게 설정함

### IMF의 목적 함수

$$

\min_{P,Q}\sum_u\sum_i
c_{ui}(p_{ui}-p_u^\top q_i)^2+
\lambda\left(\sum_u\|p_u\|^2+\sum_i\|q_i\|^2\right)

$$

- 사용자·아이템의 모든 조합을 고려함
- 신뢰도를 활용해 각 데이터의 중요도를 다르게 반영함
- 관측되지 않은 상호작용도 낮은 신뢰도로 학습에 반영함

교재 실험 결과

- Precision@K = 0.026
- Recall@K = 0.080

해당 실험에서는 앞서 소개한 MF보다 순위 기반 추천 성능이 높게 나타남

## 6. BPR(Bayesian Personalized Ranking)

> 사용자가 선호한 아이템의 순위를 선호하지 않았거나 관측되지 않은 아이템보다 높게 학습하는 순위 최적화 방법
> 

### BPR의 핵심 개념

- 평점 자체를 정확하게 예측하기보다 아이템 간 상대적인 순서를 학습함
- 사용자 u, 선호 아이템 i  미관측 아이템 j의 조합을 사용함
- 사용자에게 i를 j보다 높게 추천하도록 학습함

예시

- 사용자 A가 영화 X를 시청함
- 영화 Y는 시청하지 않음
- X를 Y보다 선호한다는 학습 가정을 설정함
- 예측 점수 X > Y가 되도록 학습함

단, 미관측 아이템이 실제로 싫어하는 아이템이라는 뜻 아님

### BPR의 목적 함수

$$

\max_{P,Q}\sum_{(u,i,j)\in D}
\ln\sigma(p_u^\top q_i-p_u^\top q_j)
-\lambda\Omega

$$

- $D$ → 사용자·긍정 아이템·비교 아이템의 학습 쌍 집합
- $\sigma$→ 시그모이드 함수
- $\Omega$→ 정규화 항
- 긍정 아이템의 예측 점수가 비교 아이템보다 커지도록 학습함

### IMF와 BPR의 차이

| 구분 | IMF | BPR |
| --- | --- | --- |
| 학습 목표 | 선호도 **값** 근사 | 아이템 간 **순위** 학습 |
| 학습 방식 | 신뢰도 가중 오차 최소화 | 쌍별 선호 순서 최적화 |
| 중심 개념 | 선호도와 신뢰도 | 상대적 선호 순위 |

#### 교재 실험 결과

- Precision@K = 0.022
- Recall@K = 0.071

해당 실험에서는 IMF보다 다소 낮은 결과를 보였으나, BPR은 Top-K 순위 학습에 적합한 대표적인 방법임

## 7. FM (Factorization Machines)

> 사용자와 아이템의 ID 뿐만 아니라 장르, 나이, 성별 등의 부가 정보까지 활용하여 특성 간 상호작용을 학습하는 방법
> 

### FM의 특징

- 기존 행렬 분해는 주로 사용자와 아이템의 상호작용을 모델링함
- FM은 다양한 특성(feature) 사이의 상호작용을 모델링함
- 사용자 아이템 정보 뿐 아니라 상황 및 메타데이터를 함께 활용할 수 있음
- 희소한 one-hot encoding 데이터를 효율적으로 처리할 수 있음

사용 가능한 정보

| 구분 | 예시 |
| --- | --- |
| 사용자 정보 | 사용자 ID, 나이, 성별 |
| 아이템 정보 | 영화 ID, 장르, 감독 |
| 행동 정보 | 사용자 평균 평점 |
| 상황 정보 | 시청 시간대, 기기 종류 |

### FM의 예측 함수

$$

\hat y=w_0+\sum_{i=1}^{n}w_ix_i+
\sum_{i=1}^{n}\sum_{j=i+1}^{n}
\langle v_i,v_j\rangle x_ix_j
$$

- $w_0$ → 전체 편향
- $w_ix_i$ → 각 특성의 개별 영향
- $\langle v_i,v_j\rangle x_ix_j$→ 서로 다른 두 특성 간 상호작용
- 특성 간 상호작용을 잠재 벡터의 내적으로 표현함

예시 → 사용자 나이와 영화 장르의 조합이 선호도에 미치는 영향을 학습할 수 있음

### 교재 실험 결과

| 실험 조건 | RMSE | Precision@K | Recall@K |
| --- | --- | --- | --- |
| 기본 FM | 1.054 | 0.013 | 0.040 |
| 부가 정보 추가 | 1.068 | 0.015 | 0.050 |
- 부가 정보 추가 후 Precision@K와 Recall@K 개선
- 반면 RMSE는 소폭 악화됨
- 부가 정보가 추천 순위 개선에 기여할 수 있지만 반드시 모든 지표를 개선하는 것은 아님

## 중요하게 본 내용

- **가장 기억에 남는 내용**
    - 행렬 분해는 사용자와 아이템의 평점 행렬을 잠재 요인으로 분해하여 평가하지 않은 아이템의 선호도를 예측하는 방법임
    - 특히 MF는 평점 예측에 집중하는 반면, BPR은 아이템 간 상대적인 선호 순위를 학습한다는 차이가 인상적이었음
    - 평점 예측 오차(RMSE)가 낮다고 해서 반드시 추천 성능(Precision@K, Recall@K)이 좋은 것은 아니라는 점이 기억에 남음
- **중요하다고 생각한 이유**
    - 추천 시스템의 목적에 따라 적합한 알고리즘과 평가 지표가 달라질 수 있기 때문임
    - 실제 서비스에서는 사용자가 직접 남긴 평점보다 클릭, 조회, 시청 기록 등의 암묵적 피드백을 더 쉽게 수집할 수 있으므로 IMF와 BPR의 활용도가 높다고 생각함
    - 단순히 예측 정확도를 높이는 것뿐 아니라 사용자가 실제로 선호할 아이템을 상위에 추천하는 것이 중요함
- **다른 주제와 연결되는 부분**
    - **협업 필터링** → 사용자와 아이템의 상호작용 데이터를 활용한다는 점에서 행렬 분해와 연결됨
    - **내용 기반 필터링** → FM은 장르, 사용자 정보 등 부가 정보를 함께 활용할 수 있으므로 내용 기반 추천과 결합할 수 있음
    - **추천 시스템 평가** → RMSE와 Precision@K, Recall@K의 차이를 통해 평점 예측과 순위 추천의 목적이 다르다는 점을 이해할 수 있음

## 질문 및 토론거리

- 이해가 어려웠던 부분
    - SVD, NMF, MF 모두 행렬을 분해하는 방식인데 실제 학습 과정과 최적화 방법에서 어떤 차이가 있는지 이해하기 어려웠음
    - IMF에서 상호작용이 없는 아이템을 선호도 0으로 설정하면서도 신뢰도를 별도로 부여하는 이유가 헷갈렸음
- **팀원들과 함께 이야기할 질문**
    - 영화 추천 시스템을 개발한다면 평점 예측에 집중하는 MF와 추천 순위에 집중하는 BPR 중 어떤 방법이 더 적합할까?
    안현지: 추천 목록을 보여주는거라면 BPR이 좋을 것 같다. 이런 영화는 어떤지 목록을 보여주는거라서
    이동민: 예측을 통해 불완전한 데이터를 보충하고 그를 바탕으로 추천 순위 BPR에 적용하면 좋을 것 같다.
    이윤성: 사용자들이 아이템에 대해 선호하는 것에 대해 우선순위를 정하는 BPR이 더 적합할 것 같다.
    - 사용자 평점 데이터가 부족한 상황에서는 IMF나 BPR 같은 암묵적 피드백 기반 추천이 더 효과적일까?
    안현지: 효과적일거 같다. 별점 같은 건 사용자가 직접 남겨야만 생기는 건데 시청 기록 같은건 자동으로 쌓이기 때문이다.
    이동민: 효과적이긴 하지만 명시적인 피드백 기반을 확실하게 구성한 다음에 사용하는 것이 좋을 것 같다.
    이윤성: 선호함에도 불구하고 선호 표시를 명확하게 하지 않는 사용자들이 많다는 경향성으로 미루어 보아 효과적일 것으로 보인다.

## 스터디 후 보완

- 새롭게 이해한 내용
    - 행렬 분해는 단순히 평점 행렬의 차원을 줄이는 것이 아니라, 사용자와 아이템의 잠재 요인을 학습하여 관측되지 않은 선호도를 예측하는 방법임
    - MF는 실제 평점의 예측 오차를 최소화하는 반면, BPR은 사용자가 선호하는 아이템이 더 높은 순위에 오도록 학습한다는 차이를 이해함
    - RMSE가 낮다고 반드시 Precision@K나 Recall@K가 높은 것은 아니며, 평점 예측과 추천 순위 최적화는 서로 다른 목표라는 점을 이해함
- 수정하거나 추가할 내용
    - SVD, NMF, MF가 모두 행렬 분해에 속하지만, 행렬을 분해하는 방식과 학습 조건에 차이가 있다는 점을 추가로 정리할 필요가 있음
    - 암묵적 피드백에서 상호작용이 없다는 것이 반드시 비선호를 의미하지는 않으며, IMF는 이를 신뢰도를 통해 반영한다는 내용을 보완함
    - 실제 추천 시스템에서는 평점 데이터의 유무, 사용자 행동 기록, 아이템의 부가 정보 등을 고려하여 적절한 알고리즘을 선택해야 함
    - 그룹 영화 추천 시스템에 적용할 경우 개인별 잠재 요인으로 선호도를 예측한 뒤, 그룹 구성원의 만족도와 불만을 함께 고려하는 재랭킹 방식도 검토할 필요가 있음
