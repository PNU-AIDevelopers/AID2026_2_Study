계산 그래프의 노드를 코드로 옮기면 "계층"

5.3절에서 계산 그래프를 손으로 그리며 역전파를 했어요. 5.4절은 그 노드를 파이썬 클래스로 옮기는 절이에요. 이렇게 만든 클래스 하나를 계층(layer)이라고 불러요. 신경망의 기능 단위라는 뜻이고, 5.5절의 ReLU·Sigmoid, 5.6절의 Affine도 모두 같은 방식의 계층이에요.

먼저 5.3절에서 배운 규칙 두 개만 기억하면 돼요. 역전파는 언제나 상류(출력 쪽)에서 온 미분 × 그 노드의 국소 미분이에요.

덧셈 노드 z = x + y∂z/∂x = 1, ∂z/∂y = 1

상류 값을 그대로 양쪽에 흘려보내요. 순전파 때 입력이 뭐였는지 몰라도 돼요.

곱셈 노드 z = x × y∂z/∂x = y, ∂z/∂y = x

상류 값에 상대편 입력을 곱해요. 그래서 순전파 때 입력을 기억해 둬야 해요.

계층은 신경망 그림의 노드(동그라미) 하나인가요?

아니에요. 책에 나오는 동그라미 그림이 두 종류라서 헷갈리기 쉬워요.

신경망 그림 (3장)계산 그래프 (5장)
동그라미 하나뉴런 하나 (숫자 하나를 담음)연산 하나 (×, +, exp, sigmoid…)
세로 한 줄층 (입력층·은닉층·출력층)해당 없음

5장의 계층은 "연산 하나를 맡는 코드 한 블록"이에요. forward와 backward를 가진 클래스 하나가 계층 하나예요.

  • 5.4절처럼 단순한 예에서는 × 노드 하나가 MulLayer 하나라서 노드 하나 = 계층 하나로 딱 맞아요.
  • 하지만 항상 노드 하나는 아니에요. Sigmoid 계층은 노드 4개(×, exp, +, /)를 묶은 블록이고, 5.6절의 Affine 계층은 수많은 곱셈·덧셈을 행렬 곱 한 번으로 묶은 블록이에요.
  • 계층은 뉴런 하나가 아니라 배열 전체를 한꺼번에 처리해요. 은닉 뉴런이 50개면 ReLU 계층 하나가 50개 값을 동시에 처리해요.

신경망 그림의 층 한 칸은 코드에서 계층 두 개로 나뉘어요. 가중치를 곱하고 편향을 더하는 계산(Affine)과 활성화 함수(ReLU, Sigmoid)를 각각 계층으로 만들거든요. 5.7절의 2층 신경망으로 대응시키면 이래요.

신경망 그림:  [입력층 784] ────→ [은닉층 50] ────→ [출력층 10]

코드의 계층:  입력 → Affine1 → Relu1 → Affine2 → SoftmaxWithLoss → 손실
                   └ x·W1+b1 ┘└ 활성화 ┘└ ·W2+b2 ┘└ 확률 + 채점 ┘
                   └── 은닉층 한 칸 ──┘ └──── 출력층 한 칸 ────┘

영어로는 둘 다 layer라서 더 헷갈려요. 신경망 그림의 "층"은 뉴런의 묶음이고, 5장의 "계층"은 연산 덩어리예요.

역전파에서는 왜 받는 것과 돌려주는 게 뒤집히나요?

순전파와 역전파는 묻는 질문이 달라요.

  • 순전파는 "재료를 넣으면 결과가 뭐야?"를 물어요. 그래서 입력(x, y)을 받아서 출력(out)을 돌려줘요.
  • 역전파는 "결과가 이렇게 나왔는데, 재료마다 얼마나 책임이 있어?"를 물어요. 그래서 결과 쪽 정보(dout)를 받아서 재료 쪽 정보(dx, dy)를 돌려줘요.

역전파는 맨 끝에서 앞쪽으로 "너는 결과에 이만큼 영향을 줬어"라는 메시지를 넘기는 릴레이예요. 사과 예제라면 소비세 계층이 뒤에서 1을 받아 "내 앞의 200은 1.1만큼 책임이 있네"를 계산해 넘기고, 사과 계층이 그 1.1을 받아 "가격은 2.2, 개수는 110만큼 책임이 있네"를 계산해요. 각 계층은 받은 메시지에 자기 몫을 곱해서 앞으로 넘길 뿐이에요.

5.4.1 · pp.160–162

곱셈 계층 MulLayer

class MulLayer:
    def __init__(self):
        self.x = None          # 순전파 입력을 담을 자리
        self.y = None

    def forward(self, x, y):
        self.x = x             # ① 입력을 저장 (역전파 때 필요)
        self.y = y
        out = x * y
        return out

    def backward(self, dout):
        dx = dout * self.y     # ② x 쪽에는 y를 곱함
        dy = dout * self.x     #    y 쪽에는 x를 곱함 (서로 바꿔서)
        return dx, dy
  • forward는 곱한 값을 돌려주면서 입력 x, y를 저장해요. 곱셈의 역전파는 상대편 입력이 필요하기 때문이에요.
  • backward는 상류에서 받은 dout에 저장해 둔 값을 바꿔서 곱해요. 입력이 두 개였으니 미분도 두 개(dx, dy)를 돌려줘요.

사과 쇼핑을 한 줄씩 실행해 보기 (그림 5-16, buy_apple.py)

사과 100원 × 2개 × 소비세 1.1을 계산해요. 다음 ▶을 누르면 코드가 한 줄씩 실행되면서 그래프에 값이 채워지고, 각 계층이 무엇을 저장하는지 오른쪽에 보여요. 파란 숫자가 순전파 값, 주황 숫자가 역전파(미분) 값이에요.

책이 강조하는 두 가지 (p.162)

① backward()는 forward()의 반대 순서로 호출해요. 순전파가 사과 계층 → 소비세 계층이었으니 역전파는 소비세 계층 → 사과 계층이에요. 각 계층은 "자기 출력에 대한 미분"을 받아야 하는데, 그 값은 바로 뒤 계층이 먼저 계산해 줘야 생기거든요.
② backward()가 받는 인수는 "순전파 출력에 대한 미분"이에요. mul_apple_layer는 순전파 때 apple_price(200)를 출력했으니, 역전파 때는 그 미분인 dapple_price(1.1)를 받아요. 앞 계층의 backward 결과가 다음 계층의 backward 입력이 되는 사슬이에요.
결과값의미

직접 실행하면 220.00000000000003처럼 끝자리가 붙어 나올 수 있어요. 컴퓨터의 소수 계산 오차라서 정상이에요.

곱셈 계층은 왜 x 쪽에 y를, y 쪽에 x를 "바꿔서" 곱하나요?

직사각형 넓이로 생각하면 쉬워요. 넓이 = 가로 × 세로 = 100 × 2 = 200이라고 해볼게요(그림은 비율을 맞추지 않았어요).

  • 가로를 1 늘리면 길이 1, 폭 2짜리 띠가 붙어서 넓이가 2(= 세로) 늘어요.
  • 세로를 1 늘리면 길이 100, 폭 1짜리 띠가 붙어서 넓이가 100(= 가로) 늘어요.

한쪽의 영향은 상대편 길이가 정해요. 사과로 바꾸면, 사과 가격이 1원 오를 때 총액은 산 개수(2)만큼 늘고, 사과를 1개 더 살 때 총액은 사과 가격(100)만큼 늘어요. 그래서 dx = dout × y, dy = dout × x이고, 이 계산에 상대편 값이 필요하니까 순전파 때 self.x, self.y를 저장해 둬요.

class AddLayer:
    def __init__(self):
        pass              # 저장할 게 없음

    def forward(self, x, y):
        out = x + y
        return out

    def backward(self, dout):
        dx = dout * 1     # 그대로 통과
        dy = dout * 1
        return dx, dy

사과 2개 + 귤 3개 (그림 5-17, buy_apple_orange.py)

곱셈 계층 3개와 덧셈 계층 1개를 조립해요. 순전파는 (1)→(4) 순서, 역전파는 (4)→(1) 순서예요. 덧셈 계층에서 1.1이 사과 쪽과 귤 쪽으로 똑같이 나뉘어 흘러가는 순간을 눈여겨보세요.

책의 결론(p.164)은 이래요. 코드는 길어 보여도 한 줄 한 줄은 단순해요. 필요한 계층을 만들고, forward()를 순서대로 부르고, 같은 계층들의 backward()를 반대 순서로 부르면 원하는 미분이 전부 나와요. 계산 그래프가 아무리 커져도 이 방식은 똑같아요.

왜 dprice = 1에서 시작하나요?

역전파가 구하는 건 "각 입력이 최종 출력(지불 금액)에 주는 영향"이에요. 최종 출력을 자기 자신으로 미분하면 ∂price/∂price = 1이라서, 맨 끝에 1을 넣고 거꾸로 곱해 나가요. 신경망에서는 이 자리에 손실 L이 오고, 똑같이 dout = 1로 시작해요.

덧셈 계층은 양쪽에 그대로 보내나요, 나눠서 보내나요?

뒤에서 받은 값을 양쪽에 똑같이 복사해서 그대로 보내요. 사과+귤 예제에서 덧셈 계층은 1.1을 받아 사과 쪽에도 1.1, 귤 쪽에도 1.1을 보내요. 0.55씩 반으로 나누지 않아요.

바꿔 보기덧셈 결과변화
사과 쪽을 1 올림201 + 450 = 651+1
귤 쪽을 1 올림200 + 451 = 651+1

어느 쪽을 1 올려도 합계가 똑같이 1 늘고, 상대편 값과 상관없어요. 그래서 각 입력의 영향은 "받은 값 × 1"이에요. 1.1을 두 쪽에 다 보냈다고 영향이 2.2로 불어난 게 아니라, "사과만 바꾸면 1.1", "귤만 바꾸면 1.1"처럼 각자 따로 잰 영향이에요.

이게 신경망이랑 무슨 상관이에요?

신경망의 계산도 결국 곱셈(입력 × 가중치), 덧셈(+ 편향), 활성화 함수의 조합이에요. 5.5절부터는 같은 forward/backward 틀로 신경망에 쓰는 계층을 만들어요.

5.5.1 · pp.165–166

ReLU 계층: 순전파 때 켜진 스위치만 역전파도 통과

이제 계산 그래프를 신경망에 적용해요. 활성화 함수도 forward/backward를 가진 계층으로 만들어요. 이번에는 입력이 숫자 하나가 아니라 넘파이 배열이라고 가정해요.

ReLU는 3장에서 배운 활성화 함수예요. 은닉층의 가중합(Affine 결과)을 받아서 음수는 0으로 잘라내고, 양수는 그대로 내보내요. 5.7절의 신경망에서는 Affine1 → Relu1 → Affine2처럼 두 Affine 계층 사이에 들어가요.

순전파 (식 5.7)y = x (x > 0)
y = 0 (x ≤ 0)
미분 (식 5.8)∂y/∂x = 1 (x > 0)
∂y/∂x = 0 (x ≤ 0)

그래서 역전파는 두 경우뿐이에요. 순전파 때 x가 0보다 컸으면 상류 값을 그대로 흘리고(× 1), 0 이하였으면 0을 보내요(× 0).

순전파 입력 x상태순전파 출력 y역전파 (상류 미분 0.7이 오면)
1.0ON 활성화됨1.00.7 × 1 = 0.7 (통과)
−0.5OFF 비활성00.7 × 0 = 0 (막힘)

0보다 커서 통과하는 상태를 뭐라고 부르나요? 켜진 값만 역전파에 반영된다는 뜻인가요?

정해진 한 단어가 있다기보다 보통 "뉴런이 활성화됐다(activated)", "신호가 통과한다", "켜졌다"라고 해요. 책은 전기 회로에 빗대 "스위치가 ON"이라고 해요. 0 이하라서 막힌 상태는 "비활성", "꺼졌다", "OFF"예요.

그리고 맞아요. 순전파 때 켜졌던 칸만 역전파 때 기울기가 앞쪽으로 전달돼요. 꺼진 칸은 기울기가 0이라서, 그 뉴런으로 이어진 가중치는 이번 데이터로는 갱신되지 않아요. "이번 답에 기여하지 않았으니 고칠 책임도 없다"는 뜻이에요.

미분 그래프(주황 선)는 왜 직각 계단 모양인가요?

주황 선은 역전파가 흐르는 모습이 아니라, x마다 ReLU의 기울기가 얼마인지를 그린 거예요. 역전파 때 곱해지는 값이 이거예요. ReLU 그래프(파란 선)는 직선 두 개를 이어 붙인 모양이에요.

  • x < 0: 바닥에 붙은 평평한 선이라 어디서 재든 기울기가 0이에요.
  • x > 0: 45도 대각선이라 어디서 재든 기울기가 1이에요.
  • x = 0: 두 직선이 뾰족하게 꺾여서 기울기가 0에서 1로 한순간에 바뀌어요.

구간 안에서는 기울기가 변하지 않으니 평평하고, 0에서 갑자기 바뀌니 직각 계단이 돼요. Sigmoid는 꺾이는 곳 없이 매끄러운 곡선이라 미분도 부드러운 언덕 모양이에요. 꺾이면 계단, 매끄러우면 언덕이라고 기억하면 돼요.

x = 0일 때 ReLU의 미분은 1인가요, 0인가요?

x = 0은 그래프가 꺾이는 점이라 엄밀히는 미분이 정해지지 않아요. 책의 코드는 x <= 0으로 처리해서 0으로 봐요. 실무 라이브러리도 보통 이렇게 한쪽으로 정해 두고 써요.

코드 (common/layers.py)

class Relu:
    def __init__(self):
        self.mask = None

    def forward(self, x):
        self.mask = (x <= 0)   # ① 0 이하인 칸을 True로 기록
        out = x.copy()         # ② 원본을 지키려고 복사
        out[self.mask] = 0     # ③ True인 칸만 0으로
        return out

    def backward(self, dout):
        dout[self.mask] = 0    # ④ 순전파 때 막힌 칸은 역전파도 0
        dx = dout
        return dx
  • ① mask: True/False로 된 넘파이 배열이에요. ReLU가 역전파를 위해 기억할 건 "어느 칸이 0 이하였나" 이것뿐이에요.
  • ② x.copy(): 복사하지 않고 x[mask] = 0을 하면 함수 밖의 원래 데이터까지 0으로 바뀌어요.
  • ③ out[self.mask] = 0: 넘파이의 불리언 인덱싱이에요. mask가 True인 칸만 골라서 한 번에 0으로 바꿔요.
  • ④ dout[self.mask] = 0: 순전파 때 만든 mask를 그대로 다시 써서, 막혔던 칸의 미분을 0으로 만들어요.

mask 자세히 보기

mask는 원래 "가림판"이라는 뜻이에요. 입력과 같은 모양의 True/False 배열로, 어느 칸을 가릴지(0으로 만들지) 표시해 둔 지도예요. ReLU 계층은 이 가림판 하나로 순전파와 역전파를 모두 처리해요.

① 만들기: 비교 연산 한 번이면 칸마다 True/False

>>> x = np.array([[1.0, -0.5], [-2.0, 3.0]])
>>> mask = (x <= 0)        # 칸마다 "0 이하인가?"를 물어봄
>>> print(mask)
[[False  True]
 [ True False]]

넘파이에서 x <= 0은 숫자 하나가 아니라 배열의 모든 칸을 한꺼번에 비교해요. 0 이하인 칸(가릴 칸)은 True, 0보다 큰 칸(통과할 칸)은 False예요. True가 "막을 칸"이라는 점만 기억하면 돼요.

② 쓰기: True인 칸만 골라서 바꾸기 (불리언 인덱싱)

>>> x[mask]                # True인 칸의 값만 골라냄
array([-0.5, -2. ])
>>> out = x.copy()
>>> out[mask] = 0          # True인 칸에만 0을 넣음
>>> print(out)
[[1. 0.]
 [0. 3.]]
>>> print(x)               # copy 덕분에 원본은 그대로
[[ 1.  -0.5]
 [-2.   3. ]]

배열 뒤 대괄호에 True/False 배열을 넣으면 True인 칸만 골라져요. 여기에 = 0을 하면 반복문 없이 그 칸들만 한 번에 0이 돼요. 이게 out[self.mask] = 0과 dout[self.mask] = 0이 하는 일이에요.

③ 저장해 두는 이유: 역전파에서 같은 가림판을 다시 씀

역전파 때 "순전파에서 어느 칸이 막혔었나"를 알아야 그 칸의 미분을 0으로 만들 수 있어요. 그래서 forward에서 만든 mask를 self.mask에 저장해 두고 backward에서 그대로 꺼내 써요. 순전파 때 가린 칸을 역전파 때도 같은 가림판으로 가리는 거예요.

신경망에서는 mask가 꽤 커요. 배치 100장, 은닉 뉴런 50개면 ReLU 계층에 들어오는 x가 (100, 50) 배열이라 mask도 (100, 50)이에요. forward를 부를 때마다 mask가 새로 덮어써지니까, backward는 반드시 방금 forward한 그 데이터에 대해 불러야 해요.
책의 NOTE: ReLU는 전기 회로의 스위치와 같아요. 순전파 때 전류가 흐르면(x > 0) 스위치를 켜고, 흐르지 않으면 꺼요. 역전파 때는 그 스위치 상태가 그대로라서, 켜져 있으면 전류가 흐르고 꺼져 있으면 더는 흐르지 않아요.

ReLU는 왜 x가 아니라 mask를 저장하나요?

역전파에 필요한 정보가 "어느 칸이 0 이하였나"뿐이라서요. 0보다 컸던 칸은 × 1, 0 이하였던 칸은 × 0이니까 x의 실제 값은 필요 없어요.

ReLU의 backward가 받은 dout을 직접 바꾸는데 괜찮나요?

책의 코드는 dout[self.mask] = 0으로 받은 배열을 그 자리에서 고쳐서 돌려줘요. 결과는 맞지만, 호출한 쪽에서 원래 dout을 다시 쓰려 하면 바뀐 값이 보여요. 신경 쓰이면 dx = dout.copy() 후에 0을 넣으면 돼요.

5.5.2 · pp.167–170

Sigmoid 계층: 4단계로 쪼개서 거꾸로 곱하기

시그모이드는 y = 1 / (1 + exp(−x))예요(식 5.9). 한 번에 미분하기 복잡해 보이지만, 계산 그래프로 쪼개면 노드 4개의 단순한 계산이 돼요(그림 5-19). 5.4절에 없던 노드가 두 개 새로 나와요.

exp 노드 y = exp(x)∂y/∂x = exp(x)

미분해도 자기 자신이라서, 역전파 때 순전파 출력을 그대로 곱해요(식 5.11).

/ 노드 y = 1/x∂y/∂x = −1/x² = −y²

역전파 때 순전파 출력을 제곱해 마이너스를 붙인 값을 곱해요(식 5.10).

이 절이 보여주는 것

  1. 복잡한 함수도 쪼개면 역전파할 수 있어요. 시그모이드를 단순한 노드 4개로 쪼개고, 뒤에서부터 국소 미분을 하나씩 곱하기만 하면 전체 미분이 나와요. 5.4절의 덧셈·곱셈에 exp와 / 두 가지만 더 알면 돼요.
  2. 결과가 y(1 − y)로 아주 간단해져요. 순전파 출력 y 하나만 있으면 역전파를 계산할 수 있어서, 코드는 출력만 저장해요.
  3. 노드 여러 개를 계층 하나로 묶을 수 있어요. 중간 노드 4개를 sigmoid 노드 하나로 묶어도 결과가 같아요. "계층 = 연산 덩어리"의 실제 예예요.
다음 ▶ 누르기오른쪽 노드(/)부터 하나씩 강조되면서, 그 노드에서 곱하는 값과 지금까지 곱한 결과(주황 숫자)가 나와요.
x 슬라이더x를 바꾸면 모든 값이 다시 계산돼요. x가 몇이든 4단계 결과와 y(1 − y)가 같게 나와요.
숫자 읽는 법화살표 위의 파란 숫자는 순전파 값, 아래의 주황 숫자는 그 지점까지 거꾸로 곱해 온 미분이에요.

중간 과정을 묶어서 sigmoid 노드 하나로 (그림 5-21)

4단계를 거친 최종 결과 ∂L/∂y · y² · exp(−x)는 순전파의 입력 x와 출력 y만으로 계산돼요. 그래서 중간 노드 4개를 sigmoid 노드 하나로 묶을 수 있어요. 책은 두 가지 장점을 들어요.

  • 역전파의 중간 계산을 생략할 수 있어서 더 효율적이에요.
  • 노드를 묶으면 내부 사정은 감추고 입력과 출력에만 집중할 수 있어요.

한 번 더 정리하면 y(1 − y) (식 5.12)

∂L/∂y · y² · exp(−x)4단계로 얻은 결과
= ∂L/∂y · 1/(1+exp(−x))² · exp(−x)y = 1/(1+exp(−x))를 대입
= ∂L/∂y · 1/(1+exp(−x)) · exp(−x)/(1+exp(−x))제곱을 두 조각으로 나눔
= ∂L/∂y · y · (1 − y)앞 조각은 y, 뒤 조각은 1 − y

뒤 조각이 1 − y인 이유: exp(−x)/(1+exp(−x)) = (1+exp(−x) − 1)/(1+exp(−x)) = 1 − 1/(1+exp(−x)) = 1 − y

결국 Sigmoid의 역전파는 순전파 출력 y 하나만 있으면 계산돼요(그림 5-22). 위의 따라 하기에서 4단계 결과와 y(1 − y)가 항상 같은 값으로 나오는 것도 이 때문이에요.

class Sigmoid:
    def __init__(self):
        self.out = None

    def forward(self, x):
        out = 1 / (1 + np.exp(-x))
        self.out = out          # 출력 y를 저장 (입력은 저장 안 함)
        return out

    def backward(self, dout):
        dx = dout * (1.0 - self.out) * self.out   # dout × (1 − y) × y
        return dx
미분이 최대 0.25라는 건 역전파 때 Sigmoid 층을 하나 지날 때마다 기울기가 최소 4분의 1로 줄어든다는 뜻이에요. 층을 여러 개 쌓으면 앞쪽 층에 도착하는 기울기가 거의 0이 돼서 학습이 잘 안 돼요. 이게 6장에서 다루는 기울기 소실이고, 요즘 은닉층에 ReLU를 많이 쓰는 이유 중 하나예요.

Sigmoid는 왜 입력이 아니라 출력을 저장하나요?

역전파 공식 y(1 − y)가 출력 y만으로 계산되기 때문이에요. 입력 x를 저장해 두면 역전파 때 sigmoid를 한 번 더 계산해야 해서 손해예요.

이것만은 기억하기

  • 계층 = 계산 그래프의 노드를 클래스로 만든 것. 모두 forward()와 backward()를 가져요.
  • 곱셈 계층은 입력을 저장했다가 바꿔서 곱하고, 덧셈 계층은 저장 없이 그대로 흘려요.
  • 역전파는 순전파의 반대 순서로 부르고, 각 backward는 "자기 출력에 대한 미분"을 받아요. 시작값은 1이에요.
  • ReLU는 mask로 순전파 때 막힌 칸을 기억했다가 역전파도 막아요.
  • Sigmoid는 4단계(/, +, exp, ×)를 거꾸로 곱하면 y(1 − y)가 되고, 그래서 출력 y만 저장해요.
