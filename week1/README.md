## 💬 스터디 회고

이번 주 스터디에서 좋았던 점, 어려웠던 점, 개선할 점 등을 자유롭게 작성해주세요.

- 좋았던 점: 팀원들 모두 적극적으로 의견을 내어 스터디의 방향성을 빠르고 명확하게 잡을 수 있었음.

- 개선할 점: 어려웠던 점과 동일
