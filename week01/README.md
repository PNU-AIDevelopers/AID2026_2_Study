## 💬 스터디 회고

- **좋았던 점**
  - 추천 시스템을 단순히 알고리즘의 관점에서만 보는 것이 아니라 **목표 설정 → 데이터 → 알고리즘 → 시스템 구현 → 평가**의 전체 흐름으로 이해할 수 있었음.
  - 팀원별로 서로 다른 범위를 담당하여 추천 시스템의 역사부터 실제 서비스 적용까지 폭넓게 학습할 수 있었음.
  - 검색과 추천의 차이, 데이터 편향, 개인화 추천 등 실제 서비스와 연결되는 사례를 함께 이야기할 수 있었음.

- **어려웠던 점**
  - 클릭·별점 등의 행동 데이터가 실제 사용자의 선호를 정확히 의미하는지 판단하기 어려웠음.
  - 신규 사용자나 신규 아이템처럼 데이터가 부족한 상황에서 어떻게 추천할 것인지 이해가 필요했음.
  - 추천 기능 자체의 성과와 서비스 전체의 성과를 구분하여 평가하는 과정이 중요하면서도 어려웠음.

- **개선할 점**
  - 개념 설명뿐만 아니라 유튜브, 넷플릭스, 아마존 등 실제 서비스 사례를 더 많이 연결해 보기
  - Precision, Recall, 데이터 편향 등 핵심 용어를 팀 전체가 공통된 기준으로 정리하기
  - 스터디 이후 나온 질문과 토론 결과를 각자의 정리 자료에 추가하여 보완하기
