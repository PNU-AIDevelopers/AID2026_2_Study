## 📎 공부 내용 정리

### 1. 데이터 전처리와 분류 (2-2)

- 부리 길이와 높이를 `np.column_stack()`으로 합쳐 `(49, 2)` 입력 배열을 구성함.
- 타깃은 A를 나타내는 `1` 35개와 B를 나타내는 `0` 14개로 구성함.
- `train_test_split(..., stratify=bird_target, random_state=42)`로 클래스 비율을 고려해 분할함.
- 거리 기반 모델에서는 단위가 같더라도 특성의 값 범위가 다르면 각 특성이 거리에 미치는 영향이 달라짐.
- **표준점수 = (값 − 훈련 세트 평균) / 훈련 세트 표준편차**
- 테스트 세트와 새 샘플에도 훈련 세트에서 계산한 평균·표준편차를 적용함.

원문의 핵심 코드이며, 원본 데이터와 라이브러리 import가 준비되어 있다는 전제임.

```python
bird_data = np.column_stack((beak_length, beak_height))
bird_target = np.concatenate((np.ones(35), np.zeros(14)))

train_input, test_input, train_target, test_target = train_test_split(
    bird_data, bird_target, stratify=bird_target, random_state=42
)

mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
test_scaled = (test_input - mean) / std
new = ([11.5, 4.0] - mean) / std

kn = KNeighborsClassifier()
kn.fit(train_scaled, train_target)
print(kn.score(test_scaled, test_target))  # 원문 결과: 1.0
```

새 샘플 `[11.5, 4.0]`의 예측은 표준화 전후 모두 `0`이었음. 표준화가 반드시 예측 클래스를 바꾸는 것은 아니며, 두 특성이 거리 계산에 반영되는 비중을 조정한다는 점을 확인함.

※ 원문의 클래스 비율 설명에는 타깃 구성과 맞지 않는 클래스 표기가 있어, 여기서는 `stratify`의 역할만 정리함.

### 2. k-최근접 이웃 회귀 (3-1)

- 분류는 클래스를 예측하지만, 회귀는 연속적인 수치를 예측함.
- 부리 길이를 입력으로, 부리 높이를 타깃으로 사용함. 분류 실습과 입력·타깃 구성이 다름.
- KNN 회귀는 가까운 이웃들의 타깃 평균으로 예측함.
- 훈련·테스트 입력을 각각 `reshape(-1, 1)`로 변환해 2차원 배열로 준비함.
- **결정계수(R²)**로 회귀 성능을 평가하고, **평균 절대 오차(MAE)**로 타깃과 같은 단위의 오차를 확인함.
- 이웃 수가 작으면 모델이 데이터의 세부 변화에 민감해지고, 크면 예측이 완만해짐. 훈련·테스트 성능을 함께 비교해야 함.

| 설정 | 훈련 R² | 테스트 R² | MAE |
|---|---|---|---|
| KNN 회귀, k=5 | 원문 미기재 | 0.9817 | 0.1615 |
| KNN 회귀, k=3 | 0.9874 | 0.9800 | 원문 미기재 |

### 3. 선형 회귀와 다항 회귀 (3-2)

- KNN은 학습 범위를 크게 벗어나도 끝부분의 가까운 이웃들로 예측하므로, 새로운 추세를 외삽하기 어려움.
- 선형 회귀는 `높이 = 계수 × 길이 + 절편`의 직선 관계를 학습함. 원문 계수는 약 `-0.607`, 절편은 `11.746`임.
- 다항 회귀는 입력에 길이의 제곱을 추가하여 곡선 관계를 표현함. 입력은 비선형으로 확장하지만 계수에 대해서는 선형 모델임.

```python
# 회귀용 훈련·테스트 입력과 타깃이 준비된 상태에서 실행
train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))

lr = LinearRegression()
lr.fit(train_poly, train_target)
print(lr.score(train_poly, train_target))
print(lr.score(test_poly, test_target))
print(lr.predict([[30 ** 2, 30]]))
```

| 모델 | 훈련 R² | 테스트 R² | 길이 30.0 입력 시 높이 예측 |
|---|---|---|---|
| KNN 회귀 (k=3) | 0.9874 | 0.9800 | 2.8 |
| 선형 회귀 | 0.8297 | 0.7235 | -6.46 |
| 2차 다항 회귀 | 0.8551 | 0.7745 | -30.94 |

원문에서 길이 범위는 8.2~15.5로 제시됨. 30.0은 학습 범위를 벗어난 입력으로, KNN은 끝부분 이웃의 평균을 반환하고 선형·다항 회귀는 현실적으로 불가능한 음수 높이를 예측함. **테스트 점수가 높아도 학습 범위 밖의 예측이 타당하다는 뜻은 아님.** 다항 회귀는 이번 실습에서 선형 회귀보다 점수가 높았지만, 외삽 문제까지 해결하지는 못함.

※ 수치와 단위 표기는 원문 기록을 따름. 이 문서 작성 과정에서 노트북을 재실행한 결과는 아님.

### 4. 특성 공학과 규제 (3-3, 개념 정리)

이 부분은 핀치새 실습 결과가 아니라 **교재의 농어 데이터에 대한 개념 및 결과 정리**임.

- **특성 공학**: 기존 특성의 제곱과 교차곱 등으로 새로운 특성을 생성함.
- `PolynomialFeatures(include_bias=False)`를 사용하면 원본 특성 3개를 2차에서 9개, 5차에서 55개로 확장할 수 있음.
- 훈련 샘플 42개에 특성 55개를 사용한 교재 예제에서는 훈련 R²가 1.0이지만 테스트 R²는 -144.41로, 심한 과대적합이 나타남.
- **과대적합**: 훈련 데이터의 잡음이나 세부 특징까지 학습하여 새로운 데이터에 대한 성능이 떨어지는 상태.
- **과소적합**: 모델이 데이터의 관계를 충분히 학습하지 못해 훈련 데이터에서도 성능이 낮은 상태.
- **규제**: 계수 크기에 벌점을 부여해 모델이 지나치게 복잡해지는 것을 억제함.
- 특성을 확장한 뒤 `StandardScaler`를 훈련 세트에만 `fit()`하고, 테스트 세트에는 같은 기준으로 `transform()`을 적용함.

| 모델 | 규제 방식 | 계수에 미치는 영향 |
|---|---|---|
| 릿지 (Ridge) | 계수 제곱합, L2 | 계수를 작게 만들며 일반적으로 정확히 0으로 만들지는 않음 |
| 라쏘 (Lasso) | 계수 절댓값합, L1 | 일부 계수를 0으로 만들어 특성 선택 효과를 낼 수 있음 |

| 교재 모델 | 훈련 R² | 테스트 R² |
|---|---|---|
| 다중 회귀 (2차, 9개 특성) | 0.9903 | 0.9715 |
| 다중 회귀 (5차, 55개 특성) | 1.0000 | -144.41 |
| 릿지 α=1 | 0.9896 | 0.9791 |
| 릿지 α=0.1 | 0.9904 | 0.9828 |
| 라쏘 α=1 | 0.9898 | 0.9801 |
| 라쏘 α=10 | 0.9888 | 0.9824 |

`alpha`가 커질수록 규제가 강해짐. 지나치게 크게 설정하면 과소적합이 발생할 수 있음. 원문에 정리된 교재의 라쏘 α=10 사례에서는 55개 계수 중 40개가 0이 되어 15개 특성이 사용됨.
