## 📎 공부 내용 정리

- 훈련 세트는 모델 학습에 사용하고, 테스트 세트는 학습한 모델의 성능 평가에 사용한다.
- 데이터를 나눌 때 특정 종류에 치우치는 샘플링 편향에 주의해야 한다.
- 거리 기반 모델에서는 특성의 단위와 값의 범위가 결과에 영향을 줄 수 있다.
- 표준점수는 각 값에서 평균을 빼고 표준편차로 나누어 계산한다.
- 테스트 데이터와 새로운 데이터는 훈련 데이터에서 구한 기준으로 변환한다.
