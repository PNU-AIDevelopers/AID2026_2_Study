- `3주차_이윤성.md` — 추천 알고리즘 분류와 내용 기반 필터링

### 주요 학습 내용

1. **추천 알고리즘의 분류:** 내용 기반 필터링과 협조 필터링은 추천에 활용하는 정보가 다르며, 메모리 기반과 모델 기반은 예측 수행 방식에서 차이가 있음.
2. **추천 방식별 장단점:** 내용 기반 필터링은 아이템 특징을 활용하고 초기 데이터 부족 상황에 대응하기 유리하지만, 협조 필터링은 사용자 행동 데이터가 충분할 때 다양한 선호 관계를 활용할 수 있음.
3. **추천 알고리즘 선택:** 데이터의 양, 추천 목적, 다양성의 필요성, 운영 비용을 고려해야 하며, 상황에 따라 여러 알고리즘을 결합할 수 있음.
4. **기호 데이터의 획득:** 별점·설문 등의 명시적 피드백과 클릭·구매 등의 암묵적 피드백은 수집 방식과 해석상의 한계가 다름.
5. **데이터 활용 시 주의점:** 평가하지 않은 아이템을 비선호로 단정해서는 안 되며, 데이터 희박성, 시간에 따른 선호 변화, 평가 편향 등을 고려해야 함.

### 주요 토론 내용

- **초기 추천 방식:** 사용자 행동 데이터가 부족한 초기에는 내용 기반 필터링이나 인기 아이템 추천을 활용하고, 데이터가 축적되면 협조 필터링과의 결합을 고려할 수 있다는 의견을 공유함.
- **미평가 아이템 처리:** 평가 기록이 없다는 사실만으로 비선호를 판단할 수 없으며, 유사 사용자나 아이템 특징을 활용해 선호를 예측할 필요가 있음을 논의함.
- **정확도와 다양성:** 추천 정확도를 기본으로 고려하되, 새로운 아이템의 발견이 중요한 서비스에서는 다양성도 함께 고려해야 한다는 의견이 제시됨.
- **행동 데이터 해석:** 구매나 클릭이 반드시 개인의 선호를 의미하지 않으며, 행동의 목적과 맥락에 따라 해석이 달라질 수 있음을 확인함.
