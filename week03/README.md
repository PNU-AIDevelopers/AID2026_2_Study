# Week 03 — 신경망 학습 (Chapter 4)

## 🎯 이번 주 목표

- 신경망이 데이터로부터 학습하는 원리를 이해하고, 훈련 데이터와 시험 데이터를 구분하는 이유를 설명한다.
- 손실 함수, 수치 미분, 편미분, 기울기, 경사하강법의 관계를 이해하고 간단한 계산에 적용한다.
- 미니배치 학습과 `TwoLayerNet`의 구조를 파악하고, 가중치·편향이 갱신되는 전체 흐름을 이해한다.

---

## 📚 스터디 진행상황

4장의 주요 개념을 읽고, 신경망이 **예측 → 손실 계산 → 기울기 계산 → 매개변수 갱신**을 반복하며 학습하는 과정을 중심으로 정리했다. 아래는 교재 및 개인 예습·질의응답에서 다룬 내용이며, 팀 전체의 실제 발표·실습 진행 여부는 별도 확인이 필요하다.

### 진행 내용

- **4.1 데이터에서 학습한다:** 사람이 특징을 일일이 규칙으로 지정하는 방식과 데이터 기반 학습을 비교하고, 훈련 데이터·시험 데이터 및 일반화의 의미를 학습했다.
- **4.2 손실 함수:** 평균 제곱 오차(MSE)와 교차 엔트로피 오차(Cross Entropy Error)의 수식을 살펴보고, 정확도와 손실 함수의 차이 및 미니배치 손실 계산을 정리했다.
- **4.3 수치 미분:** 중앙 차분식으로 미분값을 근사하는 방법을 익히고, 여러 매개변수에 대한 편미분의 필요성을 확인했다.
- **4.4 기울기:** 기울기 벡터와 경사하강법의 관계를 이해하고, 학습률에 따라 손실이 감소하거나 증가할 수 있음을 계산 예시로 살펴봤다. 가중치 행렬과 기울기 행렬의 형태가 같다는 점도 확인했다.
- **4.5 학습 알고리즘 구현:** `simpleNet`과 `TwoLayerNet`의 역할, `W1`·`b1`·`W2`·`b2`의 차원, 미니배치 추출과 매개변수 갱신 반복문의 흐름을 개념 중심으로 살펴봤다. 실제 코드의 세부 분석과 실행 결과 검증은 추가 학습이 필요하다.

## 💬 스터디 회고

- **좋았던 점:** 손실 함수부터 경사하강법과 학습 반복문까지, 개별적으로 보였던 개념이 하나의 학습 과정으로 연결된다는 점을 이해했다. 간단한 수치 계산과 행렬 차원 예제가 개념 이해에 도움이 됐다.
- **어려웠던 점:** 특정 이차함수의 편미분 결과를 모든 손실 함수에 적용할 수 있다고 혼동했다. 또한 기울기의 반대 방향이면 무조건 손실이 감소한다고 생각했던 점, 손실 함수와 정확도 및 훈련 성능과 일반화 성능을 구분하는 점이 어려웠다.
- **개선할 점:** 수식의 의미만 이해하는 데서 그치지 않고 직접 `numerical_gradient`와 `TwoLayerNet` 코드를 실행해 가중치 형태 및 손실·정확도 변화를 확인한다. 개념 설명 뒤에는 작은 계산 문제와 코드 실행 결과를 함께 점검한다.
