## 내가 맡은 범위

- **담당 절·주제**
4.1 추천 알고리즘 분류
4.2 내용 기반 필터링
- **이 범위를 맡은 이유 또는 연결되는 내용**
평소 사용하는 서비스가 어떤 기준으로 콘텐츠를 추천하는지 궁금해서 맡게 됨. 추천 알고리즘의 기본 분류부터 이해하고, 내 취향과 비슷한 콘텐츠를 찾아주는 원리를 알아보고 싶었음.

## 배운 내용 정리

### 내용 1 — 추천 알고리즘의 분류

- **내용 기반 필터링**
사용자가 좋아하는 특징과 아이템의 특징을 비교하여 추천하는 방식임. 예를 들어 미스터리 장르를 좋아하는 사용자에게 같은 장르의 책을 추천함.
- **협조 필터링**
다른 사용자들의 행동과 선호 관계를 활용하여 추천하는 방식임. 예를 들어 나와 비슷한 책을 좋아한 사람이 구매한 다른 책을 추천함.
- **메모리 기반 방법**
협조 필터링의 한 종류로, 추천 시점에 축적된 데이터를 직접 활용하여 예측을 계산함.
- **모델 기반 방법**
협조 필터링의 한 종류로, 축적된 데이터의 규칙성을 미리 학습한 모델을 만들고 이를 이용하여 예측함.
- **분류 기준**
내용 기반과 협조 필터링은 **‘추천에 사용하는 정보’**로 구분함. 메모리 기반과 모델 기반은 ‘예측을 수행하는 방식’으로 구분함.

### 내용 2 — 내용 기반 필터링의 추천 원리

- **사용자 프로필**
사용자가 선호하는 특징을 정리한 정보임. 좋아하는 작가·장르·출판사 등이 해당함.
- **아이템 특징**
추천 대상 자체의 속성을 나타내는 정보임. 책이라면 해당 책의 작가·장르·출판사 등이 해당함.
- **유사도**
사용자 프로필과 아이템 특징이 얼마나 비슷한지를 나타내는 정도임. 내용 기반 필터링에서는 유사도가 높은 아이템을 추천함.
- **추천 과정**
사용자 프로필 파악 → 아이템 특징과 비교 → 유사도가 높은 아이템 선택 순서로 이루어짐.
- **교재 예시**
아이템 A는 사용자가 선호하는 작가와 장르가 모두 일치하고, 아이템 B는 작가만 일치함. 이 예시에서는 A가 사용자 프로필과 더 비슷하다고 판단하여 추천함.

### 내용 3 — 아이템 특징과 사용자 프로필 획득

- **아이템 특징 획득**
아이템을 설명할 수 있는 속성을 수집하거나 분석으로 추출하는 과정임. 데이터 종류에 따라 얻을 수 있는 특징이 달라짐.
- **책의 특징**
제목·장르·작가·출판일 등의 속성 정보를 활용할 수 있음.
- **음악의 특징**
작곡가·작곡 연도 등의 속성 정보와 음성 분석으로 얻은 음의 높이·음색·음량 등을 활용할 수 있음.
- **이미지의 특징**
촬영 장소·시간 등의 속성 정보와 이미지 분석으로 얻은 색채·형태 등을 활용할 수 있음.
- **간접 지정**
사용자의 과거 행동을 바탕으로 선호를 추정하여 프로필을 만드는 방식임. 구매한 책에 SF 장르가 자주 등장하면 SF를 선호한다고 추정할 수 있음.
- **직접 지정**
사용자가 자신의 선호를 직접 입력하여 프로필을 만드는 방식임. 가입할 때 관심 장르를 선택하거나 마이 페이지에서 좋아하는 작가를 설정하는 경우임.

## 중요하게 본 내용

- **가장 기억에 남는 내용**
추천에 앞서 아이템의 특징과 사용자의 취향을 비교할 수 있는 형태로 정리해야 한다는 점임.
- **중요하다고 생각한 이유**
특징이나 취향이 제대로 표현되지 않으면 유사도를 계산해도 적절한 추천으로 이어지기 어렵기 때문임.
- **다른 주제와 연결되는 부분
ML**에서 데이터의 특징을 추출하는 과정과 연결됨. 음성 분석이나 이미지 분석으로 얻은 정보도 추천에 활용할 수 있음.

## 질문 및 토론거리

- **이해가 어려웠던 부분**
    - 작가·장르·출판사처럼 서로 다른 특징을 비교할 때, 각 특징의 중요도는 어떻게 정해야 할까?
    - 사용자가 직접 입력한 취향과 구매 이력에서 추정한 취향이 다르면, 어떤 정보를 기준으로 프로필을 만들어야 할까?
- **팀원들과 함께 이야기할 질문**
    - 선물이나 과제 때문에 구매한 아이템도 사용자가 좋아한다고 판단해도 될까?
        - 김민서: 사용자의 선호가 반영된 아이템이 아니기 때문에 판단에서 제외해야 된다고 생각한다.
        - 안현지: 구별할 수 있다면 사용자의 선호로 선택한 것이 아닌 것들은 제외해야될 것 같다.
        - 이동민: 선물과 과제 같은 경우, 다음에도 비슷한 구매나 행위가 일어날 가능성이 존재하기 때문에 어느정도 포함할 가치가 있다.
    - 기존 취향과 비슷한 아이템만 추천하면 새로운 취향을 발견할 기회가 줄어들지 않을까?
        - 김민서: 정보추 수업에서 실제로 개인화의 단점 중에 filter bubble인가 concentration이 있었던 거 같다.
        - 안현지: 새로운 취향을 발견할 기회는 줄어들겠지만 비슷한 아이템을 추천받을때가 유용할 때도 많기때문에 상황에따라 다를 것 같다.
        - 이동민: 새로운 것을 발견하는 경험도 중요하지만 사용자가 주로 사용하는 인터페이스에서 억지로 끼워넣기 보다는 사용자 스스로 탐색하는 공간을 마련하는 방식이 좋을 것 같다.

## 스터디 후 보완

- **새롭게 이해한 내용**
내용 기반 필터링에서도 구매 이력을 활용할 수 있으며, 이때는 구매한 아이템의 특징으로 사용자의 취향을 파악한다는 점을 이해함.
- **수정하거나 추가할 내용**
구매 이력이 반드시 선호를 의미하지는 않으므로, 간접 지정으로 만든 프로필에는 오차가 있을 수 있다는 점을 추가함.
