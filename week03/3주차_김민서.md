## 다양성 향상

> 추천 결과에 포함된 아이템이 서로 얼마나 다른지 나타내는 개념
> 
- **협조 필터링이 유리**
    - 다른 사람들의 행동 데이터를 활용하므로 사용자가 기존에 알지 못했던 새로운 장르나 아이템도 추천할 수 있음
    - 비슷한 취향을 가진 사용자가 좋아하는 아이템 추천 → 다양한 아이템을 발견할 가능성이 높음
    - ex) 액션 영화를 좋아하는 사용자에게 비슷한 취향의 다른 사용자들이 좋아하는 SF 영화도 추천함
- **내용 기반 필터링이 불리**
    - 사용자의 기존 선호 정보와 유사한 특징을 가진 아이템을 추천
    - 사용자가 경험하지 않은 새로운 장르나 특징은 사용자 프로필에 반영되기 어려움
    - ex) 액션 영화를 좋아하는 사용자에게 액션 장르의 영화 위주로 추천함
    
    ⇒ 추천 결과가 기존 취향과 비슷한 아이템에 집중될 가능성 높음
    

## 도메인 지식 취급 비용

> 추천 시스템을 구축하고 운영하기 위해 아이템과 사용자에 대한 전문적인 정보를 관리하는 데 드는 비용
> 
- **협조 필터링이 유리**
    - 사용자들의 과거 평가 및 행동 데이터를 기반으로 추천
    - 아이템 자체의 특징이나 사용자 속성 정보를 반드시 분석할 필요가 없음
    - 도메인 지식을 별도로 구축하고 관리하는 비용이 상대적으로 낮음
    - ex) 사용자들이 어떤 책을 구매하고 평가했는지만 활용하여 추천함
- **내용 기반 필터링이 불리함**
    - 아이템의 특징과 사용자 프로필을 분석하기 위한 도메인 지식이 필요함
    - 이러한 정보를 수집하고 정제하며 유지하는 데 추가적인 비용이 발생함
    - 도메인 지식이 부정확하거나 부족하면 추천 품질이 저하될 수 있음
    - ex) 책의 장르, 작가, 출판사 등의 특징을 분석하여 추천함

## 콜드 스타트 문제에 대한 대응

> 새로운 사용자나 아이템이 등장했을 때 추천에 필요한 데이터가 부족하여 적절한 추천을 제공하기 어려운 문제
> 
- **협조 필터링이 불리함**
    - 사용자들의 과거 평가 및 행동 데이터에 의존함
    - 신규 사용자는 행동 이력이 없어 유사한 사용자를 찾기 어려움
    - 신규 아이템은 평가 및 이용 기록이 부족하여 추천되기 어려움
    - ex) 새로 등록된 영화는 다른 사용자들의 평가가 부족하여 추천하기 어려움
- **내용 기반 필터링이 상대적으로 유리함**
    - 신규 아이템도 특징 정보가 존재한다면 기존 사용자에게 추천할 수 있음
    - 사용자 선호 프로필만 확보되면 다른 사용자의 평가 없이도 추천할 수 있음
    - 단, 신규 사용자의 선호 정보가 전혀 없다면 내용 기반 필터링도 추천하기 어려움
    - ex) 새로 등록된 영화라도 장르, 감독, 줄거리 등의 정보를 활용하여 추천할 수 있음

## 사용자 수가 적은 서비스에서의 추천

> 서비스 이용자가 적어 충분한 사용자 행동 데이터를 확보하기 어려운 상황
> 
- **협업 필터링이 불리함**
    - 다른 사용자들의 평가, 클릭, 구매 기록 등 충분한 행동 데이터가 필요함
    - 사용자 수가 적으면 비슷한 취향을 가진 사용자를 찾기 어려움
    - 사용자와 아이템 간 상호작용 데이터가 부족해 데이터 희소성(Data Sparsity) 문제가 발생함
    - 따라서 추천 결과의 정확도와 신뢰도가 낮아질 수 있음
    - ex) 사용자 10명 중 특정 상품을 평가한 사람이 1명뿐이라면, 해당 평가를 바탕으로 다른 사용자에게 적절한 추천을 제공하기 어려움
- **내용 기반 필터링이 유리함**
    - 아이템 특징과 개별 사용자 프로필만으로도 추천이 가능함
    - 다른 사용자의 행동 데이터에 대한 의존도가 낮음
    - 따라서 초기 서비스나 사용자 수가 적은 환경에서도 상대적으로 안정적인 추천이 가능함
    - ex) 사용자 10명이라도 각 사용자의 선호 정보와 상품 특징을 활용하여 추천할 수 있음

## 커버리지 향상

> 서비스에 존재하는 전체 아이템 중 추천 시스템이 사용자에게 추천할 수 있는 아이템의 비율
> 
- **협조 필터링이 불리함**
    - 사용자들의 평가 및 행동 기록에 기반하여 추천함
    - 아무도 평가하거나 이용하지 않은 아이템은 추천하기 어려움
    - 따라서 추천 가능한 아이템이 인기 상품 등에 집중될 가능성이 있음
    - ex) 아무도 구매하거나 평가하지 않은 상품은 추천하기 어려움
- **내용 기반 필터링이 유리함**
    - 아이템 특징 정보만 존재하면 추천 후보로 활용할 수 있음
    - 다른 사용자들의 평가가 없는 아이템도 추천 가능함
    - 따라서 전체 아이템 중 추천 가능한 아이템의 비율을 높이기 쉬움
    - ex) 구매 이력이 없는 상품도 색상, 가격, 카테고리 등의 특징을 이용하여 추천할 수 있음

## 아이템 특징 활용

> 아이템이 가진 다양한 속성을 얼마나 효과적으로 분석하고 추천에 활용할 수 있는지에 대한 관점
> 
- **협조 필터링이 불리함**
    - 기본적인 협조 필터링은 사용자들의 과거 평가 및 행동 데이터를 중심으로 추천함
    - 아이템의 색상, 크기, 디자인 등 세부 특징을 직접 고려하기 어려움
    - 특징이 다른 아이템도 행동 패턴에 따라 유사하게 판단할 수 있음
    - ex) 사용자가 검은색 옷을 좋아하지만 다른 사용자들의 선호 패턴에 따라 빨간색 옷을 추천할 수도 있음
- **내용 기반 필터링이 유리함**
    - 아이템의 특징을 명시적으로 분석하여 추천함
    - 사용자 선호 정보를 바탕으로 특정 특징을 가진 아이템을 추천할 수 있음
    - 사용자가 좋아하는 특징과 싫어하는 특징을 세부적으로 구분할 수 있음
    - ex) 사용자가 검은색 옷을 선호한다는 특징을 파악하여 검은색 옷 위주로 추천함

## 예측 정확도

> 추천 시스템이 사용자의 실제 선호도나 평가값을 얼마나 정확하게 예측하는지를 나타내는 지표
> 
- **협조 필터링이 상대적으로 유리함**
    - 자신의 선호 정보뿐만 아니라 다른 사용자들의 행동 데이터도 활용함
    - 다양한 사용자의 평가를 분석하여 복잡한 취향을 반영할 수 있음
    - 서비스 이용자가 증가하고 데이터가 축적되면 예측 정확도 향상을 기대할 수 있음
    - ex) 비슷한 취향의 다른 사용자들이 특정 영화를 높게 평가했다면 해당 사용자도 좋아할 가능성이 높다고 예측함
- **내용 기반 필터링이 불리함**
    - 사용자의 기존 선호 정보와 아이템 특징을 기반으로 예측함
    - 다른 사용자들의 행동 정보를 직접 활용하지 않으므로 파악할 수 있는 선호 패턴에 한계가 있음
    - 아이템 특징이나 사용자 프로필이 불충분하면 예측 정확도가 낮아질 수 있음
    - ex) 사용자가 좋아하는 영화의 장르, 배우, 감독 등의 특징을 분석하여 선호도를 예측함

## 중요하게 본 내용

- 가장 기억에 남는 내용: 협조 필터링과 내용 기반 필터링은 각각 장단점이 있으며, 모든 상황에서 우수한 알고리즘은 존재하지 않는다
- 중요하다고 생각한 이유:실제 추천 시스템을 개발할 때 단순히 예측 정확도가 높은 알고리즘을 선택하는 것이 아니라, 서비스의 규모와 데이터 확보 상황을 고려해야 하기 때문
- 다른 주제와 연결되는 부분:
    - 하이브리드 추천 시스템 → 협조 필터링과 내용 기반 필터링을 결합하여 서로의 단점을 보완할 수 있음
    - 콜드 스타트 문제 → 신규 사용자나 아이템의 데이터 부족 문제를 해결하기 위해 콘텐츠 특징이나 사용자 초기 선호도 조사를 활용할 수 있음

## 질문 및 토론거리

- 이해가 어려웠던 부분:
    - 협조 필터링이 내용 기반 필터링보다 예측 정확도가 높다고 하지만, 실제로 어떤 상황에서 정확도가 역전될 수 있는지 궁금함
    - 협조 필터링의 추천 다양성이 높다는 것이 반드시 사용자 만족도 향상으로 이어지는지 궁금함
- 팀원들과 함께 이야기할 질문:
    - 우리가 추천 시스템 프로젝트를 개발한다면, 초기 사용자 행동 데이터가 부족한 상황에서 어떤 추천 방식을 선택하는 것이 좋을까?
        - 이윤성: 내용 기반 필터링으로 시작하는 것이 초기 사용자 맞춤형 정보를 효과적으로 적용하고 제공하는 것에 있어 더 유리할 것이다. 내용 기반 필터링이 사용자 본인에 포커스를 맞춘 것이 그 이유이다.
        - 안현지: 내용 기반 필터링으로 시작하면 좋을 것 같다. 협조필터링은 행동 데이터가 쌓여야 작동되지만 내용 기반은 아이템 속성만으로도 가능하기 때문이다.
        - 이동민: 내용 기반 필터링으로 시작하고, 얻은 데이터를 효율적으로 관리하고 이후의 데이터를 예측하거나 설계하는 시스템이 필요하다.
    - 협조 필터링과 내용 기반 필터링을 결합한다면 어떤 기준으로 두 알고리즘의 추천 결과를 반영하는 것이 좋을까?
        - 이윤성: 협조 필터링을 위주로 한 여러 가지 선택지 중 상위 몇 가지의 선지를 신규 사용자에게 제공하고, 이 중 선호하는 것이 없을 경우 ‘기타’ 항목에 직접 작성하게끔 한다. 이를 바탕으로 내용 기반 필터링(선택한 선지들의 조합)을 적용하면 사용자 맞춤형 정보를 제공하는 것이 용이해질 것이다.
        - 안현지: 신규 사용자가 많으면 내용 기반 위주로 조정하고 이력이 많은 사용자가 많다면 협조필터링 위주로 조정하는 것이 좋을 것 같다.
        - 이동민: 협조 필터링을 통해 얻은 모든 결과에 대해 다시 내용 기반 필터링을 통과시키는 것이 이상적일 것 같다. 비용에 대한 tradeoff를 어떤 방식으로 관리할지에 대한 고민이 필요하다
    - 추천 시스템에서 예측 정확도와 추천 다양성 중 무엇을 더 중요하게 고려해야 할까?
        - 이윤성: 추천 다양성이 조금 더 중요하게 작용할 것이다. 사용자 본인도 미처 인지하지 못한 취향이나 정보를 다양한 정보를 제공함으로써 선호도 및 정보를 정확하게 조정해 나갈 수 있기 때문이다.
        - 안현지: 예측 정확도를 기본으로 하되 서비스 성격에 따라서 다양성을 섞는 것이 좋을 것 같다.
        - 이동민: 제공하는 서비스에 따라 달라질 것 같다. 사용자가 정확한 결과를 원하는 시스템이라면 예측 정확도가 중요하고 다양한 경험이 필요하다면 추천 다양성이 필요하다.
