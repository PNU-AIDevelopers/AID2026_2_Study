### 내용 2 - 데이터 수집 과정에서 발생하는 편향

- **편향(Bias)**
    - 특정 방향으로 데이터나 추천 결과가 치우치는 현상
    - 오프라인 평가와 온라인 평가 사이의 괴리 발생
    - 추천 결과에 대한 사용자 만족도 및 신뢰도 저하
- **선택 편향(Selection Bias)**
    - 사용자가 자신의 기호에 따라 평가 대상을 선택하면서 발생하는 편향
    - MNAR(Missing Not At Random): 데이터가 무작위적이지 않은 방식으로 결손된 상태
    - 해결 방안
        - 데이터 대치(Data Imputation)를 통한 결측 평가값 예측
        - 경향 점수(Propensity Score)를 활용한 데이터 분포 보정
    - Example
        - 좋아하는 장르의 영화에만 평점을 남기는 사용자
        - 실제 선호도보다 높은 평점 위주로 구성된 데이터
- **동조 편향(Conformity Bias)**
    - 다른 사용자의 평가가 자신의 평가에 영향을 미치는 현상
    - 해결 방안
        - 아이템의 인기도에 따른 평가값 보정
        - 사용자 개인의 선호도 및 평가 상황 등 보조 정보 활용
    - Example
        - 다른 사용자들의 높은 영화 평점에 영향을 받아 실제 만족도보다 높은 평점 부여
- **노출 편향(Exposure Bias)**
    - 전체 아이템 중 일부만 사용자에게 노출되면서 발생하는 편향
    - 사용자 행동의 부재와 비선호를 구분할 필요성
    - 해결 방안
        - 경향 점수를 활용한 평가 지표의 가중치 조정
        - 휴리스틱(Heuristic)을 활용한 학습 손실 가중치 조정 및 다운 샘플링
    - Example
        - 사용자에게 노출된 적 없는 영화를 선호하지 않는 영화로 잘못 판단하는 경우
- **위치 편향(Position Bias)**
    - 추천 목록의 상위에 위치한 아이템에 사용자 행동이 집중되는 현상
    - 해결 방안
        - 클릭 모델(Click Model)을 활용한 사용자 행동 분석
        - 위치에 따른 경향 점수 활용
        - 결과 무작위화(Result Randomization)를 통한 위치별 영향 측정
    - Example
        - 추천 목록의 첫 번째 영화가 하위 영화보다 많은 클릭을 얻는 현상

### 내용 3 - 추천 결과의 편향과 편향 증폭

- **인지도 편향(Popularity Bias)**
    - 인기 아이템이 다른 아이템보다 더 많은 추천 기회를 얻는 현상
    - 해결 방안
        - 학습 과정에 편향 완화를 위한 정규화항 추가
        - 비주류 아이템(Niche Item)의 추천 기회 확대
    - Example
        - 유명 흥행작만 반복적으로 추천되고 독립 영화는 노출되지 않는 상황
- **불공평성(Unfairness)**
    - 특정 개인이나 집단이 부당하게 유리하거나 불리한 추천을 받는 현상
    - 해결 방안
        - 학습 데이터 및 추천 결과의 다양성 조정
        - 학습 과정에 공평성(Fairness) 관련 기준 추가
        - 성별, 인종 등 민감한 속성의 사용 최소화
    - Example
        - 특정 사용자 집단에 제한적인 종류의 콘텐츠만 반복적으로 추천하는 상황
- **피드백 루프(Feedback Loop)**
    - 사용자 행동 → 데이터 수집 → 모델 학습 → 추천 → 새로운 사용자 행동으로 이어지는 순환 구조
    - 각 단계에서 발생한 편향이 서로 영향을 미치면서 기존 편향을 증폭시키는 문제
    - 해결 방안
        - 추천 아이템 일부의 무작위 선택
        - 강화 학습(Reinforcement Learning)을 활용한 새로운 아이템 탐색
    - Example
        - 인기 영화 추천
        - 해당 영화의 조회 및 평가 증가
        - 인기도 상승
        - 추천 모델 재학습
        - 해당 영화의 추천 빈도 추가 증가

## 중요하게 본 내용

- 가장 기억에 남는 내용:
    - 피드백 루프에 의한 편향 증폭
    - 추천 시스템의 결과가 다시 학습 데이터에 반영되면서 기존 편향이 강화되는 구조
- 중요하다고 생각한 이유:
    - 높은 추천 정확도가 반드시 좋은 추천 결과를 의미하지는 않는다는 점
    - 사용자 행동 데이터가 실제 선호도를 완전하게 반영하지 않을 가능성
    - 장기적인 사용자 만족도를 위한 정확성, 다양성, 공평성의 균형 필요성
- 다른 주제와 연결되는 부분:
    - 협업 필터링(Collaborative Filtering): 편향된 사용자 평가 데이터에 따른 추천 결과 왜곡
    - 오프라인 평가(Offline Evaluation): 편향된 데이터로 인한 평가 지표의 신뢰도 저하
    - 다양성(Diversity): 인지도 편향을 완화하기 위한 다양한 아이템 추천
    - 그룹 추천(Group Recommendation): 특정 구성원에게 유리한 추천 결과가 반복되지 않도록 공평성 고려질문 및 토론거리

- 이해가 어려웠던 부분:
    - 경향 점수의 산출 방법과 이를 활용한 편향 보정 원리
    - 선택 편향과 노출 편향의 구체적인 차이
    - 강화 학습을 활용한 피드백 루프 완화 과정
- 팀원들과 함께 이야기할 질문:
    - 추천 정확도와 추천 결과의 다양성 중 어느 요소를 더 중요하게 고려해야 하는가?
        - 이동민:  사용자 입력에 따라 가중치를 변화시키는 조작을 해도 좋을 것 같다. 가중치에 따라 사용자에게 노출되는 것을 보고 사용자가 다시 판단할 수 있도록 할 수 있다.
        - 노시은:  다양성이 높을수록 사용자가 새로운 취향을 발견하고 다양한 선택지를 접할 수 있기 때문에 다양성을 더 고려하면 좋을 것 같다.
        - 김민서: 초기에는 추천 정확도로 사용자의 신뢰?를 얻은 후에 추천 다양성에 집중하면 좋을 것 같다.
        - 안현지: 서비스마다 비중이 다를 것 같다. 영화처럼 다양성이 새로운 발견이 될 수 있는 경우에는 다양성에 비중을 더 둬도 되지만 상호 추천처럼 정확도가 낮으면 사용자가 만족감을 크게 못느끼는 경우엔 정확도에 비중을 둬야될 것같다.
    - 그룹 영화 추천에서 특정 구성원의 선호도가 지속적으로 무시되는 문제를 어떻게 해결할 수 있는가?
        - 이동민: 마이너한 장르를 선호하는 사람들에게만 추천되는 영화라도 일반적으로 선호되는 작품이 될 수 있다. 리뷰나 다른 평가들을 종합해서 노출되도록 할 수 있다.
        - 노시은: 지속적으로 선호도가 무시되는 구성원의 선호에 가중치를 부여한다.
        - 김민서: 계속 모니터링해서 무시되는 구성원을 확인하고 해당 구성원에 가중치를 부여하는 방법으로 해결한다.
        - 안현지: 그룹 평균 선호도도 보지만 가장 낮은 선호도도 항상 체크하여 다음번엔 그 구성원의 의견에는 더 가중치를 부여하는 방식으로 하면 좋을 것 같다.
